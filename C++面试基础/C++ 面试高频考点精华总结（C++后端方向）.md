### 一、高频模块概览
基于你的求职方向（C++后端/Linux服务端开发），以下模块是面试中的重中之重：对标注⭐⭐⭐⭐⭐的题目（尤其是智能指针、`vector`、虚函数），必须准备到“源码级别”的理解。

|模块|重要程度|核心考察点|
|---|---|---|
|**1. C++基础语法与关键字**|⭐⭐⭐⭐⭐|`const`、`static`、`extern`、`volatile`、`sizeof`、`typedef` vs `define`、内存对齐、指针与引用|
|**2. 面向对象（OOP）**|⭐⭐⭐⭐⭐|三大特性、虚函数原理、多态实现、构造/析构、菱形继承、抽象类|
|**3. STL标准模板库**|⭐⭐⭐⭐⭐|vector/list/map底层、迭代器失效、扩容机制、resize/reserve、智能指针|
|**4. C++11/14/17新特性**|⭐⭐⭐⭐⭐|右值引用与移动语义、lambda、智能指针（shared_ptr/unique_ptr/weak_ptr）、auto/decltype|
|**5. 内存管理**|⭐⭐⭐⭐|`malloc` vs `new`、内存布局、堆与栈、深拷贝与浅拷贝、RAII|
|**6. 编译与链接**|⭐⭐⭐|静态库/动态库、编译链接过程、`extern "C"`、头文件保护|

**数据结构与算法**：**80%时间刷题** + 20%时间复习底层原理（如红黑树、哈希冲突）。

**计网/OS/数据库**：**100%时间准备八股文**，并思考如何用你的分布式项目去解释它们（如TCP粘包、多线程同步、MySQL索引）。

### 核心策略：以“分布式系统项目”为轴心，驱动所有知识点

面试官最看重的，不是你“背了多少题”，而是你“如何用学到的知识解决了实际问题”。因此，你的所有准备都应围绕你的核心项目——**分布式任务调度系统**展开。
#### 1. C++ 核心考点与项目结合

|面试模块|高频考点|你的项目结合点（话术准备方向）|
|---|---|---|
|**C++基础**|`static`、`const`、内存对齐|- **`static`**：你的`Worker`节点信息管理类中，可以用`static`成员来存储全局配置或节点ID生成器。准备时，想一下如何用`static`保证唯一性。 - **内存对齐**：在设计网络通信协议结构体时，为什么需要考虑内存对齐？可以谈谈它对网络传输效率的影响。|
|**面向对象**|虚函数、多态、构造/析构|- **多态**：你的系统中有`Master`和`Worker`，它们有共同的行为（如`handleTask()`）。可以设计一个抽象基类`Node`，用虚函数来实现多态处理。面试时，这就是一个生动的多态例子。 - **虚析构**：如果你的`Node`基类有派生类，务必保证基类析构函数是虚函数。这正是考点，也是你项目的实际需求。|
|**STL**|`vector`扩容、`map`底层、迭代器失效|- **`vector`**：`Master`维护的任务队列、`Worker`列表，用`vector`管理。准备时，深入理解`vector`扩容机制，并思考在删除失效`Worker`时，如何避免迭代器失效（这正是你项目会遇到的问题）。 - **`map`**：用`map`管理`<任务ID, 任务对象>`，其底层红黑树的有序性如何帮你实现任务超时检测？|
|**C++新特性**|智能指针、移动语义、Lambda|- **智能指针**：你的`Master`和`Worker`、任务对象等在堆上创建的对象，都应该用`unique_ptr`或`shared_ptr`管理。重点准备：为何用`shared_ptr`管理任务队列？如何用`weak_ptr`解决`Master`和`Worker`互相引用的问题？ - **Lambda**：在`ThreadPool`中，用Lambda表达式封装任务函数，简洁优雅。|
|**内存管理**|`new`/`delete`、RAII、内存分区|- **RAII**：这是你项目的核心思想。`Socket`连接、`Mutex`锁、文件句柄等资源，都应通过RAII类（如`std::lock_guard`）管理。这是向面试官展示你工程素养的最佳时机。 - **内存分区**：你的任务对象在堆上（`new`），调度线程的栈上有局部变量。结合你的项目，讲清楚动态分配和自动变量的区别。|

## 三、总结与建议

根据你的求职方向（C++后端/Linux服务端），建议优先重点掌握：

1. **虚函数与多态原理**（必问，且问得很深）
    
2. **STL容器底层与迭代器失效**（vector/map是高频）
    
3. **智能指针**（循环引用、线程安全是加分项）
    
4. **C++11新特性**（移动语义、lambda几乎必问）
    
5. **内存管理与RAII**（体现工程能力）
    

以上共 **70 道题**，覆盖了C++面试中绝大多数的核心考点，且全部引用自你提供的八股文原文。建议按照模块逐一攻克，每个问题都按“是什么 → 为什么 → 怎么实现 → 有什么问题 → 怎么优化”的逻辑准备答案，结合你自己的分布式项目进行实战演练。
