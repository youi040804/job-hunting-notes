## 题1：14. 最长公共前缀

![[Pasted image 20260811180011.png]]

### 思路

不会，直接看题解。

采用**纵向扫描**：

- 以第一个字符串作为基准；
- 按字符位置从左到右遍历；
- 每一列检查所有字符串对应位置是否相同；
- 遇到不同字符或字符串长度不足，返回当前前缀。

![[Pasted image 20260811180131.png]]

### 为什么想到？

多个字符串找公共前缀：

- 前缀必须从第一个字符开始；
- 需要比较所有字符串相同位置的字符。

因此想到：

> 字符位置扫描 + 多字符串验证。

### 复杂度

时间：O(nm)

空间：O(1)

### 相关积累

多个字符串查找公共前缀时，可以考虑纵向扫描：

- 固定字符位置；
- 遍历所有字符串进行比较。

代码：
```
string longestCommonPrefix(vector<string>& strs) {
	string& s0=strs[0];
	for(int j=0;j<s0.size();j++){
		for(string&s:strs){
			if(j==s.size()||s[j]!=s0[j]){
				return s0.substr(0,j);
			}
		}
	}
	return s0;
}
```

## 题2：151. 反转字符串中的单词

![[Pasted image 20260811180045.png]]

### 思路

不会，主要是不熟悉字符串空格处理。

学习 `stringstream`：

- 自动跳过前导空格；
- 多个连续空格视为一个分隔符；
- 使用 `while(ss >> word)` 提取单词。

流程：

字符串 → 提取单词 → vector 保存 → 倒序拼接。

### 为什么想到？

看到：

- 字符串按空格拆分；
- 忽略连续空格；
- 获取每个单词。

想到：

> 使用 stringstream 进行字符串解析。

### 复杂度

时间：O(n)

空间：O(n)

### 相关积累

C++ 字符串处理工具：

- `stringstream`
    - 按空格读取单词；
    - 自动处理连续空格。
- `getline`
    - 按指定分隔符读取字符串。

代码：
```
string reverseWords(string s) {

	stringstream ss(s);
	string word;
	vector<string> words;
	string result;

	while(ss>>word){
		words.push_back(word);
	}

	for(int i=words.size()-1;i>=0;i--){
		result+=words[i];
		if(i>0) result+=" ";
	}

	return result;
}
```
