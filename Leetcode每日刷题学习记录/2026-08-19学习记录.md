## 新题

### 1. 二叉树的层序遍历

这题是普通队列 `queue<TreeNode*>` 的典型应用，不是优先队列。每次从队首取出一个节点，再把它的左右孩子从队尾加入，访问顺序自然就是从上到下、从左到右。

难点在于题目要求按层返回 `vector<vector<int>>`。进入每一层时，先用 `int level_size = que.size();` 固定住这一层原本的节点数；虽然遍历时会不断把下一层孩子入队，但 `level_size` 不会改变，所以这一轮只会处理当前层。

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
	queue<TreeNode*>que;
	vector<vector<int>>res;
	
	if(root!=nullptr) que.push(root);
	
	while(!que.empty()){
		vector<int>tmp;
		
		for(int i=que.size();i>0;i--){
			root=que.front();
			que.pop();
			tmp.push_back(root->val);
			
			if(root->left) que.push(root->left);
			if(root->right)que.push(root->right);
	
		}
		res.push_back(tmp);
	}
	return res;
}
```

`for (int i = que.size(); i > 0; --i)` 的关键是 `que.size()` 只在 `i` 初始化时读取一次，不能把它写在循环条件中。`vector` 用 `push_back()`；`stack`、`queue`、`priority_queue` 都用 `push()`。`vector<vector<int>> res;` 本身就是一个合法的空二维数组，空树时直接返回它即可。

时间复杂度 `O(n)`，每个节点进出队各一次；空间复杂度 `O(n)`，最宽的一层可能同时在队列中。

### 2. 验证二叉搜索树

二叉搜索树的中序遍历顺序是严格递增的，所以只要在中序遍历过程中记住上一个访问节点的值 `pre`，并检查当前值是否大于 `pre` 即可。

```cpp
class Solution {
    long long pre = LLONG_MIN;

public:
    bool isValidBST(TreeNode* root) {
        if (root == nullptr) return true;

        if (!isValidBST(root->left)) return false; // 左
        if (root->val <= pre) return false;        // 中
        pre = root->val;
        return isValidBST(root->right);            // 右
    }
};
```

递归会先一路走到最左边的空节点，再逐层返回处理节点，所以实际访问顺序正是“左 → 中 → 右”。`pre` 是成员变量，不会随着递归返回而恢复，它始终表示中序遍历中前一个已经访问的节点值。题目节点值可能为 `INT_MIN`，所以用 `long long` 配合 `LLONG_MIN`，避免哨兵值冲突。

时间复杂度 `O(n)`；递归栈空间为 `O(h)`，最坏退化成链时为 `O(n)`。

### 3. 二叉搜索树中第 K 小的元素

BST 的中序遍历结果从小到大，因此访问到第 `k` 个真实节点时，它就是答案。最直观的做法是把中序遍历结果存到 `vector` 后返回 `result[k - 1]`，但会遍历完整棵树并额外使用 `O(n)` 空间。

更进一步，可以让 `k` 引用传递：每访问一个节点就 `--k`；当 `k == 0` 时直接返回节点值。`-1` 表示当前子树没有找到答案；一旦下层返回的不是 `-1`，上一层也直接 `return` 这个值，因此后面的节点不会再访问。

```cpp
class Solution {
public:
    int kthSmallest(TreeNode* root, int& k) {
        if (root == nullptr) return -1;

        int left_res = kthSmallest(root->left, k);
        if (left_res != -1) return left_res;

        if (--k == 0) return root->val;

        return kthSmallest(root->right, k);
    }
};
```

牢记：`return` 会结束当前函数；如果上一层把递归结果也直接 `return`，答案就会沿调用栈逐层向上传递。提前找到第 `k` 小时，实际访问量是到该节点之前的路径和节点数，可描述为 `O(h + k)`；最坏情况下第 `k` 小接近最后一个节点，仍是 `O(n)`。递归栈空间为 `O(h)`。

### 4. 二叉树的右视图

右视图本质上还是层序遍历，只是每一层只保留最后出队的那个节点值。因为当前层节点按从左到右顺序出队，所以这一层最后一次更新的 `last` 就是从右边看到的节点。

```cpp
vector<int> rightSideView(TreeNode* root) {

	vector<int>res;
	queue<TreeNode*>que;
	
	if(root!=nullptr)  que.push(root);
	
	while(!que.empty()){
		int tmp;
		
		for(int i=que.size();i>0;i--){

			TreeNode*root=que.front();
			tmp=root->val;
			que.pop();
	
			if(root->left) que.push(root->left);
			if(root->right) que.push(root->right);
		}          
		res.push_back(tmp);
	}
	return res;
}
```

易错点：`queue` 用 `push()`、`front()`，不是 `push_back()`、`top()`；每次循环要用当前取出的 `node` 操作孩子，不能继续使用最外层的 `root`。

时间复杂度 `O(n)`，空间复杂度 `O(n)`。

## 今日小结

- 三种 DFS 遍历只差“处理当前节点”的位置：前序 `中左右`，中序 `左中右`，后序 `左右中`。
- 普通二叉树按层处理时，用队列 + 固定当前层节点数。
- BST 的中序遍历严格递增，可以用来验证 BST、寻找第 K 小元素。
- 递归提前返回的关键：找到答案后，每一层都把这个结果直接 `return` 回去。

| 容器类型                   | 添加元素的方法                        | 说明            |
| ---------------------- | ------------------------------ | ------------- |
| `vector`               | `push_back()`                  | 只能在末尾添加元素     |
| `list`（双向链表）           | `push_back()` 和 `push_front()` | 两端都可以添加元素     |
| `deque`（双端队列）          | `push_back()` 和 `push_front()` | 两端都可以添加元素     |
| `stack`（栈）             | `push()`                       | 只能从栈顶入栈       |
| `queue`（队列）            | `push()`                       | 只能从队尾入队       |
| `priority_queue`（优先队列） | `push()`                       | 插入元素并自动按优先级排序 |

## C++标准容器的三大分类

|分类|包含的容器|核心特点|
|---|---|---|
|**序列容器（Sequence Containers）**|`vector`、`list`、`deque`、`array`、`forward_list`|元素按**线性顺序**排列，每个元素有固定位置（由插入顺序决定），你可以控制元素放在哪里|
|**关联容器（Associative Containers）**|`set`、`map`、`multiset`、`multimap`|元素按**键值（key）**自动排序和存储，位置由键决定，不是由插入顺序决定，查找速度快（红黑树实现）|
|**无序关联容器（Unordered Associative）**|`unordered_set`、`unordered_map`、`unordered_multiset`、`unordered_multimap`|也是按键存储，但使用**哈希表**，元素**不排序**，查找平均O(1)|
|**容器适配器（Container Adapters）**|`stack`、`queue`、`priority_queue`|不是独立的容器，而是**包装**在底层容器之上，提供特定的接口（如LIFO、FIFO）|
