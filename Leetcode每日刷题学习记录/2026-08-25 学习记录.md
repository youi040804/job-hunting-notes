## 1. 232. 用栈实现队列

### 类型

栈 + 数据结构模拟。

### 核心思路

队列是先进先出，栈是后进先出。

使用两个栈：

- `stk1`：负责接收新元素；
- `stk2`：负责出队。

当需要 `pop()` 或 `peek()` 时：

- 如果 `stk2` 不为空，直接使用 `stk2`；
- 如果 `stk2` 为空，就把 `stk1` 中的元素全部弹出并压入 `stk2`。

经过一次倒栈后，原本最早进入 `stk1` 的元素会来到 `stk2` 栈顶，从而实现 FIFO。

### 四个操作

#### push

直接压入 `stk1`。

```cpp
stk1.push(x);
```

#### pop

如果 `stk2` 为空，先把 `stk1` 全部倒入 `stk2`，然后弹出 `stk2` 栈顶。

#### peek

和 `pop` 一样需要保证队头位于 `stk2.top()`，但只查看，不删除。

#### empty

只有两个栈同时为空时，队列才为空。

```cpp
return stk1.empty() && stk2.empty();
```

### 关键点

> 一个栈负责“进”，一个栈负责“出”；只有出栈为空时，才进行倒栈。

不能每次 `pop` 都重新倒栈，否则会破坏已经排好的出队顺序。

### 我的漏洞

第一次看到这题时没有想到“两个栈经过两次逆序可以得到队列顺序”。

需要记住：

> 栈本身只能逆序一次，两个栈组合可以利用两次逆序实现 FIFO。

另外，`pop()` 和 `peek()` 的区别只在于最后是否执行 `stk2.pop()`。

### 复杂度

- `push`：O(1)
- `pop`：均摊 O(1)
- `peek`：均摊 O(1)
- `empty`：O(1)

每个元素最多从 `stk1` 移动到 `stk2` 一次，因此整体是均摊 O(1)。
