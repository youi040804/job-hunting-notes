### 1. 面试题 17.14. 最小 K 个数

这题和之前做过的“数组中的第 K 个最大元素”属于同一个 Top K 堆模型，只不过方向正好相反。

如果要维护数组中最小的 `k` 个元素，就可以使用一个大小最多为 `k` 的**大顶堆**。这样堆顶始终是当前这 `k` 个候选元素中最大的那个，也就是最应该被淘汰的元素。


核心逻辑：

```cpp
priority_queue<int>pq;
for(int x:arr){
	pq.push(x);
	if(pq.size()>k){
		pq.pop();
	}
}
```

当堆还不足 `k` 个元素时，直接加入。

当堆已经有 `k` 个元素时：

```text
如果 x >= pq.top()
```

说明当前元素比“目前第 k 小的候选值”还要大，它不可能进入最终最小的 `k` 个数，直接忽略。

如果：

```text
x < pq.top()
```

说明新元素更小，应该进入候选集合，因此先淘汰当前候选中最大的元素：

```cpp
pq.pop();
pq.push(x);
```

最后堆里的 `k` 个元素就是答案。

代码：

```cpp
class Solution {
public:
    vector<int> smallestK(vector<int>& arr, int k) {
        vector<int>ans;
        priority_queue<int>pq;
        for(int x:arr){
            pq.push(x);
            if(pq.size()>k){
                pq.pop();
            }
        }
        while(!pq.empty()){
            ans.push_back(pq.top());
            pq.pop();
        }
        return ans;
    }
};
```

这里也顺便重新确认了 C++ `priority_queue` 的写法：

```cpp
// 大顶堆
priority_queue<int> pq;

// 小顶堆
priority_queue<int, vector<int>, greater<int>> pq;
```

`priority_queue` 的模板参数实际上是：

```cpp
priority_queue<T, Container, Compare>
```

大顶堆之所以只需要写：

```cpp
priority_queue<int>
```

是因为 C++ 默认底层容器就是 `vector<int>`，默认比较规则就是 `less<int>`。小顶堆需要把比较规则改成 `greater<int>`，因此第二个模板参数也必须一起写出来。

这题和之前的 Top K 模型可以一起记：

```text
前 K 大
→ 维护 K 个最大的元素
→ 超过 K 个时淘汰最小值
→ 小顶堆

前 K 小
→ 维护 K 个最小的元素
→ 超过 K 个时淘汰最大值
→ 大顶堆
```

时间复杂度 `O(n log k)`，额外空间复杂度 `O(k)`。


### 2. 解码方法

这题属于比较典型的线性动态规划。

定义：

```text
dp[i]
```

表示：

> 前 `i` 个字符一共有多少种合法解码方式。

例如：

```text
s = "226"
```

那么：

```text
dp[1] → "2"
dp[2] → "22"
dp[3] → "226"
```

计算 `dp[i]` 时，只需要考虑最后一步有哪两种可能。

第一种：最后一个字符单独解码。

如果：

```cpp
s[i - 1] != '0'
```

那么最后一个字符属于 `1~9`，可以单独解码，因此：

```cpp
dp[i] += dp[i - 1];
```

第二种：最后两个字符一起解码。

计算：

```cpp
int num = (s[i - 2] - '0') * 10 + (s[i - 1] - '0');
```

如果：

```cpp
10 <= num && num <= 26
```

说明最后两个字符可以共同组成一个字母，因此：

```cpp
dp[i] += dp[i - 2];
```

所以状态转移可以压缩成：

```text
如果最后一个字符 != '0'
    dp[i] += dp[i - 1]

如果最后两个字符组成 10~26
    dp[i] += dp[i - 2]
```

初始化：

```cpp
dp[0] = 1;
```

这里的 `dp[0] = 1` 可以理解为：

> 空字符串有一种“什么都不做”的解码方式。

第一个字符需要单独处理：

```cpp
if (s[0] != '0') {
    dp[1] = 1;
}
```

然后从 `i = 2` 开始同时考虑两种转移：

```cpp
class Solution {
public:
    int numDecodings(string s) {
        int n = s.size();

        vector<int> dp(n + 1, 0);

        dp[0] = 1;

        if (s[0] != '0') {
            dp[1] = 1;
        }

        for (int i = 2; i <= n; i++) {

            if (s[i - 1] != '0') {
                dp[i] += dp[i - 1];
            }

            int num =(s[i - 2] - '0') * 10 + (s[i - 1] - '0');

            if (num >= 10 && num <= 26) {
                dp[i] += dp[i - 2];
            }
        }

        return dp[n];
    }
};
```

这题最容易出错的是 `0`。

例如：

```text
"10"
```

最后一个 `'0'` 不能自己解码，因此不能从：

```text
dp[i - 1]
```

转移。

但是：

```text
"10"
```

整体可以作为一个字母，所以可以从：

```text
dp[i - 2]
```

转移。

而：

```text
"06"
```

既不能把 `0` 单独解码，`06` 也不是合法的两位编码，所以没有合法方案。

另一个容易混淆的地方是：

```text
dp[i]
```

表示的是“前 `i` 个字符”，而不是字符串下标 `i`。

所以：

```text
dp[i]
```

对应的最后一个字符串字符实际上是：

```cpp
s[i - 1]
```

这也是为什么 DP 数组要开成：

```cpp
vector<int> dp(n + 1, 0);
```

而不是 `n` 个元素。

时间复杂度 `O(n)`，空间复杂度 `O(n)`。

### 3. 50. Pow(x, n)

这题第一次接触到了一个新的通用模型：**快速幂**。

最朴素的方法是把 `x` 连乘 `n` 次，时间复杂度为：

```text
O(n)
```

但指数具有一个很重要的性质：

如果 `n` 是偶数：

```text
x^n = x^(n/2) × x^(n/2)
```

如果 `n` 是奇数：

```text
x^n = x^(n/2) × x^(n/2) × x
```

因此可以每次把指数直接缩小一半。

递归函数：

```cpp
double quickPow(double x, long long n)
```

表示计算：

```text
x^n
```

递归出口：

```cpp
if (n == 0) {
    return 1.0;
}
```

因为：

```text
x^0 = 1
```

然后先计算一半：

```cpp
double half = quickPow(x, n / 2);
```

如果 `n` 是偶数：

```cpp
return half * half;
```

如果是奇数：

```cpp
return half * half * x;
```

例如：

```text
quickPow(2, 10)
↓
quickPow(2, 5)
↓
quickPow(2, 2)
↓
quickPow(2, 1)
↓
quickPow(2, 0)
```

指数每次直接减半，而不是：

```text
10 → 9 → 8 → 7 ...
```

因此时间复杂度降到了 `O(log n)`。

负指数利用：

```text
x^(-n) = 1 / x^n
```

所以外层只需要先转换为正指数。

这里有一个 C++ 的经典溢出问题：

```cpp
int n = INT_MIN;
-n;
```

会溢出，因为：

```text
INT_MIN = -2147483648
INT_MAX =  2147483647
```

`2147483648` 已经超出了 `int` 范围。

因此必须先写：

```cpp
long long N = n;
```

再进行：

```cpp
N = -N;
```

完整代码：

```cpp
class Solution {
    double quickPow(double x, long long n) {
        if (n == 0) {
            return 1.0;
        }

        double half = quickPow(x, n / 2);

        if (n % 2 == 0) {
            return half * half;
        } else {
            return half * half * x;
        }
    }

public:
    double myPow(double x, int n) {
        long long N = n;

        if (N < 0) {
            N = -N;
            return 1.0 / quickPow(x, N);
        }

        return quickPow(x, N);
    }
};
```

快速幂目前最重要的是记住三句话：

```text
指数每次折半

偶数：half * half

奇数： half * half * x
```

负指数则额外：

```text
取倒数
```

并且先转成 `long long`，避免 `INT_MIN` 取反溢出。

时间复杂度 `O(log n)`；递归栈空间复杂度 `O(log n)`。

## 今日小结

- Top K 模型进一步补完整：前 K 大使用大小为 K 的小顶堆，前 K 小使用大小为 K 的大顶堆。核心不是“答案大就用大顶堆”，而是看候选集合中需要快速淘汰谁。
- 解码方法属于线性动态规划。`dp[i]` 表示前 `i` 个字符的解码方案数，每一步只需要考虑最后一个字符单独解码，以及最后两个字符一起解码两种情况。
- 动态规划中状态下标和原数组下标不一定是一回事。这里 `dp[i]` 表示“前 i 个字符”，所以对应字符串元素是 `s[i-1]`。
- 第一次学习快速幂：利用指数折半，将 `O(n)` 次乘法降低到 `O(log n)`。
- Pow(x,n) 还顺便复习了一个 C++ 整数边界问题：`INT_MIN` 不能直接在 `int` 范围内取反，应该先转换为 `long long`。
