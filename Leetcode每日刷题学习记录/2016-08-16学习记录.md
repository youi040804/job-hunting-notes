### 题1：2. 两数相加

![[Pasted image 20260816160303.png]]


#### 思路

一开始想到先把两个逆序链表还原成整数，求和后再拆成链表。但链表长度可能很长，`long long` 也会溢出，因此不能真的把整个数算出来。

正确做法是模拟竖式加法：每一轮只计算当前两个节点的值和上一轮的进位。当前位保存 `sum % 10`，新的进位是 `sum / 10`。
```
class Solution {

public:

ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
	
	ListNode dummy;
	ListNode* cur = &dummy;
	int carry = 0;
	
	while (l1 || l2 || carry) {
	
		int sum = carry;
	
		if (l1) {
			sum += l1->val;
			l1 = l1->next;
		}
	
		if (l2) {
			sum += l2->val;
			l2 = l2->next;
		}
		
		cur->next = new ListNode(sum % 10);
		cur = cur->next;
		carry = sum / 10;
	}
	return dummy.next;
}
```
#### 关键理解

以 `[2,4,3] + [5,6,4]` 为例：

|轮次|计算|新节点值|新进位|
|---|---|---|---|
|1|`2 + 5 + 0 = 7`|7|0|
|2|`4 + 6 + 0 = 10`|0|1|
|3|`3 + 4 + 1 = 8`|8|0|

```
cur->next = new ListNode(sum % 10);

cur = cur->next;
```

先把新节点接到当前链表尾部，再让 `cur` 移动到新尾节点。循环条件必须写成 `l1 || l2 || carry`，因为最后一位可能还有进位，例如 `[9] + [1]` 需要得到 `[0,1]`。

#### 复杂度

时间复杂度：`O(max(m, n))`  
空间复杂度：`O(max(m, n))`，结果链表不计入额外空间时为 `O(1)`。

### 题2：19. 删除链表的倒数第 N 个结点

![[Pasted image 20260816160455.png]]

#### 思路

使用固定间距的双指针。让 `right` 先走 `n` 步，然后 `left` 和 `right` 一起走；当 `right` 到达最后一个节点时，`left` 正好位于待删除节点的前一个节点。

为了统一“删除头结点”的情况，在头结点前加一个 dummy 节点。这样即使删除原头结点，也始终可以通过“前一个节点”完成删除。

```

ListNode* removeNthFromEnd(ListNode* head, int n) {

	ListNode dummy(0, head);
	ListNode* left = &dummy;
	ListNode* right = &dummy;

	while (n--) {
		right = right->next;
	}

	while (right->next) {
		left = left->next;
		right = right->next;
	}

	ListNode* nxt = left->next;
	left->next = left->next->next;
	delete nxt;

	return dummy.next;
}
```

#### 为什么先走 `n` 步，而不是 `n + 1` 步？

因为 `left` 和 `right` 一开始都位于 dummy 节点。`right` 先走 `n` 步后，二者之间正好隔着 `n` 个真实节点；随后一起走到 `right` 位于尾节点时，`left` 就正好停在倒数第 `n` 个节点的前一个节点。

例如 `1 -> 2 -> 3 -> 4 -> 5`，删除倒数第 `2` 个节点：

初始：left、right 都在 dummy

right 先走 2 步：right 到节点 2

一起走到 right 为节点 5 时：left 到节点 3

left->next 就是节点 4，可以删除

#### dummy.next 为什么用 `.` 而不是 `->`？

这里的 `dummy` 是一个实际对象：

ListNode dummy(0, head);

对象访问成员用 `.`，所以是 `dummy.next`。而 `left` 是指针：

ListNode* left = &dummy;

指针访问成员用 `->`，所以是 `left->next`。

### 题3：24. 两两交换链表中的节点

![[Pasted image 20260816160655.png]]

#### 思路

![[Pasted image 20260816160620.png]]

每次处理相邻两个节点。设当前局部结构为：

```
node0 -> node1 -> node2 -> node3
```

交换后变为：

```
node0 -> node2 -> node1 -> node3
```

dummy 的作用是让第一组节点也拥有统一的“前驱节点”，不需要单独处理头结点交换。

```

ListNode* swapPairs(ListNode* head) {

	ListNode dummy(0, head);
	ListNode* node0 = &dummy;
	ListNode* node1 = head;

	while (node1 && node1->next) {
		ListNode* node2 = node1->next;
		ListNode* node3 = node2->next;

		node0->next = node2;
		node2->next = node1;
		node1->next = node3;

		node0 = node1;
		node1 = node3;
	}
	return dummy.next;
}
```
#### 关键点

修改链表时要先保存后续节点，否则改动 `next` 后可能找不到剩余链表。每轮结束后，原来的 `node1` 已经变成这一组的尾节点，因此下一轮的 `node0` 应该更新为它。

#### 复杂度

时间复杂度：`O(n)`  
空间复杂度：`O(1)`。

### 题4：92. 反转链表 II

![[Pasted image 20260816160751.png]]
#### 思路

反转区间 `[left, right]` 时，需要保留区间前后的连接关系：

left 前一个节点 | left ... right | right 后一个节点

先让 `p0` 移动到 `left` 的前一个节点，再从 `p0->next` 开始反转 `right - left + 1` 个节点。反转结束后，原来的区间头节点会变成区间尾节点，因此它需要连接到 `cur`；随后 `p0` 再连接到新的区间头 `pre`。

```
ListNode* reverseBetween(ListNode* head, int left, int right) {

	ListNode dummy(0, head);
	ListNode* p0 = &dummy;

	for (int i = 0; i < left - 1; i++) {
		p0 = p0->next;
	}

	ListNode* pre = nullptr;
	ListNode* cur = p0->next;

	for (int i = 0; i < right - left + 1; i++) {
		ListNode* nxt = cur->next;
		cur->next = pre;
		pre = cur;
		cur = nxt;
	}

	p0->next->next = cur;
	p0->next = pre;

	return dummy.next;
}
```

![[Pasted image 20260816160759.png]]
#### 为什么循环 `right - left + 1` 次？

因为需要反转的节点数量就是闭区间 `[left, right]` 的长度。例如 `left = 2，right = 4`，需要反转节点 `2、3、4`，共 `4 - 2 + 1 = 3` 个。

你的写法：

```
while (cur != rightNext)
```

如果 `rightNext` 真的是提前保存好的“原 right 节点的下一个节点”，那么思路也是正确的。灵神的写法只是不用额外保存 `rightNext` 指针，而是直接通过确定的循环次数控制反转范围。

#### 关键连接关系

以 `1 -> 2 -> 3 -> 4 -> 5`，反转 `[2, 4]` 为例：

反转后：

pre 指向 4

cur 指向 5

p0->next 仍然是原来的 2

所以需要：

```
p0->next->next = cur; // 2 -> 5

p0->next = pre;       // 1 -> 4
```

最终得到：

```
1 -> 4 -> 3 -> 2 -> 5
```
