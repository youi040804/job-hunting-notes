### 1. 572. 另一棵树的子树

这题可以拆成两层递归：外层在 `root`中寻找可能的子树起点，内层判断"从当前节点开始的这棵树"是否和 `subRoot`完全相同。

核心思路：

-   `isSubtree`：把 `root` 中的每个节点都当作候选根节点；
-   `isSameTree`：比较两棵树的结构和节点值是否完全一致；
-   当前节点匹配失败后，继续去左子树或右子树寻找，因此使用 `||`；
-   判断两棵树完全相同时，左右子树都必须一致，因此使用 `&&`。

``` cpp
class Solution {
public:
    bool isSameTree(TreeNode* root1, TreeNode* root2) {
        if (root1 == nullptr && root2 == nullptr) return true;
        if (root1 == nullptr || root2 == nullptr) return false;
        if (root1->val != root2->val) return false;

        return isSameTree(root1->left, root2->left)
            && isSameTree(root1->right, root2->right);
    }

    bool isSubtree(TreeNode* root, TreeNode* subRoot) {
        if (root == nullptr) return false;

        if (isSameTree(root, subRoot)) return true;

        return isSubtree(root->left, subRoot)
            || isSubtree(root->right, subRoot);
    }
};
```

这里容易混淆的是为什么 `isSameTree` 必须"左和左比、右和右比"。因为判断的是两棵树是否完全相同，左右位置本身就是树结构的一部分。如果把左子树和右子树交叉比较，那判断的就不再是"相同"，而更接近"镜像"。

可以直接记成：

``` text
isSubtree：
当前节点是不是起点？
    是 -> true
    不是 -> 左边找 || 右边找

isSameTree：
两个节点都空 -> true
一个空一个不空 -> false
值不同 -> false
否则 -> 左边相同 && 右边相同
```

复杂度：设 `root` 有 `n` 个节点，`subRoot` 有 `m` 个节点。最坏情况下，`root` 中每个节点都可能作为候选起点，而每次又可能比较 `subRoot` 的大部分节点，因此时间复杂度为 `O(nm)`。额外空间来自递归栈，可写成`O(h1 + h2)`；极端退化情况下为 `O(n + m)`。

## 今日小结

-   二叉树递归题可以先拆职责：一个函数负责"找位置"，另一个函数负责"判断当前结构是否满足条件"。
-   判断两棵树完全相同时，要比较对应位置：根对根、左对左、右对右。
-   `||` 常用于"任意一边成功即可"，`&&` 常用于"左右两边都必须成功"。
-   复杂度分析时，先看外层遍历多少候选节点，再看每个候选节点内部最多做多少工作。
