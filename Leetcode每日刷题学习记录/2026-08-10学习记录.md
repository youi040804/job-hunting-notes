### 1. 除了自身以外数组的乘积（LeetCode 238）

### 思路

本题要求：

- 不能使用除法
- O(n) 时间复杂度

核心思想：

当前位置 `answer[i]` 等于：

```
左边所有元素乘积 × 右边所有元素乘积
```

因此可以拆成两次遍历：

第一次遍历：

计算当前位置左侧所有元素的乘积。

例如：

```
nums = [1,2,3,4]

left:
[1,1,2,6]
```

其中：

```
left[i] = nums[0] * ... * nums[i-1]
```

第二次遍历：

从右往左计算右侧乘积，同时更新答案。

维护变量：

```
temp = 当前元素右侧所有元素乘积
```

最终：

```
answer[i] = 左乘积 × 右乘积
```


### 为什么想到？

看到：

- 除自身
- 不能使用除法
- 求每个位置对应的其他元素关系

想到：

当前位置结果依赖其他位置的信息。

因为不能除法：

```
总乘积 / nums[i]
```

不可行。

于是转换问题：

拆成：

```
左侧贡献 + 右侧贡献
```

通过两次遍历分别计算。

只需要记住：

对于数组中的每个位置：

```
答案 = 左边乘积 × 右边乘积
```

左边一次遍历，右边一次遍历。


### 今日收获

掌握：

**前缀思想在乘积问题中的应用。**

以前前缀和：

```
sum[i]=前面所有数字的和
```

现在：

```
product[i]=前面所有数字的乘积
```

本质都是：

提前保存历史信息，避免重复计算。

### 2. 合并区间（LeetCode 56）

### 思路

核心：

排序 + 维护当前合并区间。

首先按照区间左端点排序：

例如：

```
[[1,3],[2,6],[8,10],[15,18]]
```

排序后：

```
[[1,3],[2,6],[8,10],[15,18]]
```

维护当前区间：

```
start = 当前区间左端点
end = 当前区间右端点
```

不断判断：

当前新区间是否和下一个区间重叠：

```
next.start <= end
```

如果重叠：

更新：

```
end=max(end,next.end)
```

继续向后扩展。

如果不重叠：

说明当前区间已经确定：

加入答案。

### 为什么想到？

一开始你的思路：

> 两两比较，合并两个区间。

方向是正确的。

真正的问题：

如果：

```
[1,4]
[2,3]
[3,8]
[5,10]
```

怎么办？

因为第一个合并后：

```
[1,4]
```

还需要继续和：

```
[3,8]
```

比较。

因此需要一个变量保存：

“当前已经合并出来的最大范围”。

这个变量就是：

```
end
```

它代表：

> 当前区间能够覆盖到哪里。

### 易错点

不要理解成：“合并两个区间”。

应该理解成：“维护一个正在增长的区间”。

例如：

```
[1,3]

遇到：
[2,6]

更新：
[1,6]

继续遇到：
[5,10]

更新：
[1,10]
```

整个过程：

```
一个区间不断吞并后面的区间
```

代码：
  ```
vector<vector<int>> merge(vector<vector<int>>& intervals) {
    
        sort(intervals.begin(),intervals.end());
        vector<vector<int>>ans;

        for(int i=0;i<intervals.size();){

            int t=intervals[i][1];
            int j=i+1;

            while(j<intervals.size()&&intervals[j][0]<=t){
                t=max(t,intervals[j][1]);
                j++;
            }
            
            ans.push_back({intervals[i][0],t});
            i=j;

        }
        return ans;

    }
    
  ```
### 今日收获

掌握：

**区间合并模型。**

核心：

```
排序 + 维护当前最大右边界 + 判断是否重叠
```

时间复杂度：
排序：
```
O(nlogn)
```
遍历：
```
O(n)
```
总：
```
O(nlogn)
```
