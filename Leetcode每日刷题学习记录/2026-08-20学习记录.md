### 1. 二叉搜索树的最小绝对差

BST 的中序遍历结果严格递增，因此任意两个节点的最小差值一定出现在中序遍历后相邻的两个节点之间。最直接的做法是先把中序遍历结果存进数组，再遍历数组比较相邻差值；更省空间的写法是在中序遍历过程中维护上一个访问节点值 `prev`，一边遍历一边更新最小差值。

```cpp
class Solution {
    int minDiff = INT_MAX;
    int prev = -1;// 初始化为 -1（因为节点值 >= 0）

    void inorder(TreeNode* root) {
        if (root == nullptr) return;

        inorder(root->left);

        if (prev != -1) {
            minDiff = min(minDiff, root->val - prev);
        }
        prev = root->val;

        inorder(root->right);
    }

public:
    int getMinimumDifference(TreeNode* root) {
        inorder(root);
        return minDiff;
    }
};
```

这里利用了 BST 中序遍历严格递增的性质，所以 `root->val - prev` 一定非负，不需要取绝对值。`prev` 必须跨递归层保存，因此放在成员变量中；它始终表示中序遍历中上一个已经访问的节点值。

时间复杂度 `O(n)`；递归栈空间 `O(h)`。

### 2. 路径总和

这题可以把 `targetSum` 理解成“还差多少”。每走到一个节点，就执行：

```cpp
targetSum -= root->val;
```

如果当前节点已经是叶子节点，并且此时 `targetSum == 0`，说明找到了一条根节点到叶子节点的合法路径。否则继续递归左右子树，只要任意一边返回 `true` 即可。

```cpp
bool hasPathSum(TreeNode* root, int targetSum) {
    if (root == nullptr) return false;

    targetSum -= root->val;

    if (targetSum == 0 &&
        root->left == nullptr &&
        root->right == nullptr) {
        return true;
    }

    return hasPathSum(root->left, targetSum) ||hasPathSum(root->right, targetSum);
}
```

这里 `targetSum` 使用值传递。左右子树递归时各自拿到一份副本，因此左边对 `targetSum` 的修改不会影响右边；这类“不同递归分支各算各的”的状态，用值传递很自然。

易错点：不能只判断 `targetSum == 0`，题目要求路径必须走到叶子节点。

时间复杂度 `O(n)`；递归栈空间 `O(h)`。

### 4. 二叉树的最近公共祖先

这题的关键是理解递归返回值：左右子树不是单纯“返回 p 或 q”，而是把当前子树中找到的有效结果往上传。这个有效结果可能是 `p`、`q`，也可能是下面已经找到的最近公共祖先。

递归分三种情况：

1. 当前节点本身就是 `p` 或 `q`：直接返回当前节点。
2. 左右子树都返回非空：说明 `p`、`q` 分居当前节点两边，当前节点就是最近公共祖先。
3. 只有一边非空：把这一边的结果继续往上传。

```cpp
TreeNode* lowestCommonAncestor(TreeNode* root,TreeNode* p,TreeNode* q) {
    if (root == nullptr) return nullptr;

    if (root == p || root == q) return root;

    TreeNode* left =lowestCommonAncestor(root->left, p, q);
    TreeNode* right =lowestCommonAncestor(root->right, p, q);

    if (left != nullptr && right != nullptr) {
        return root;
    }

    return left != nullptr ? left : right;
}
```

最容易漏掉的是：

```cpp
if (root == p || root == q) return root;
```

因为题目规定一个节点也可以是它自己的祖先，所以如果 `p` 本身就是 `q` 的祖先，那么 `p` 就是最近公共祖先，反之同理。

时间复杂度 `O(n)`；递归栈空间 `O(h)`。

## 今日小结

- BST 中序遍历严格递增，可以把树转换成“有序序列”来思考；最小差值只需要比较中序相邻节点。
- 二叉树递归中，如果左右分支的状态应该彼此独立，值传递通常更自然；如果所有递归层需要共享同一状态，再考虑引用或成员变量。
- “路径总和”属于从根向下传递状态的 DFS；“最近公共祖先”属于利用左右子树返回值做判断的后序递归。
