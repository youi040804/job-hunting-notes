### 1. 200. 岛屿数量

类型：网格 DFS + 连通块。

核心思路：

遍历整个网格，每遇到一个还没有访问过的 `'1'`，说明发现了一座新的岛：

```cpp
count++;
dfs(grid, i, j);
```

DFS 从当前位置出发，把与它上下左右连通的所有 `'1'` 都访问一遍。

这题直接把访问过的陆地改成 `'0'`：

```cpp
grid[i][j] = '0';
```

相当于使用 `visited` 标记，可以避免重复访问和无限递归。

DFS 的终止条件：

```cpp
if (i < 0 || i >= grid.size() ||
    j < 0 || j >= grid[0].size()) {
    return;
}

if (grid[i][j] == '0') {
    return;
}
```

然后继续访问四个方向：

```cpp
dfs(grid, i - 1, j);
dfs(grid, i + 1, j);
dfs(grid, i, j - 1);
dfs(grid, i, j + 1);
```

完整代码：

```cpp
class Solution {
public:
    void dfs(vector<vector<char>>& grid, int i, int j) {
        if (i < 0 || i >= grid.size() ||
            j < 0 || j >= grid[0].size()) {
            return;
        }

        if (grid[i][j] == '0') {
            return;
        }

        grid[i][j] = '0';

        dfs(grid, i - 1, j);
        dfs(grid, i + 1, j);
        dfs(grid, i, j - 1);
        dfs(grid, i, j + 1);
    }

    int numIslands(vector<vector<char>>& grid) {
        int count = 0;

        for (int i = 0; i < grid.size(); i++) {
            for (int j = 0; j < grid[0].size(); j++) {
                if (grid[i][j] == '1') {
                    count++;
                    dfs(grid, i, j);
                }
            }
        }

        return count;
    }
};
```

复杂度：

- 时间：`O(mn)`，每个格子最多被处理一次；
- 空间：最坏 `O(mn)`，主要来自 DFS 递归栈。

## 今日小结

- 二维网格中出现“上下左右连通区域”，优先想到 DFS / BFS。
- 遇到一个未访问节点，可以从它出发处理整个连通块。
- DFS 基本流程：边界判断 → 已访问判断 → 标记当前节点 → 递归访问相邻节点。
- 修改原网格也可以充当 `visited` 标记。
