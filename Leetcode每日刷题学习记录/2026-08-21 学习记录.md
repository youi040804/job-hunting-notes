### 1. 74. 搜索二维矩阵

这题本质上还是普通二分查找，只是数据以二维矩阵的形式存储。由于题目保证每一行递增，并且下一行的第一个元素大于上一行的最后一个元素，因此整个矩阵按照行展开以后，其实就是一个完整的递增数组。

不需要真的创建一个一维数组，只需要把二维矩阵逻辑上看成长度为 `m * n` 的一维数组。对于一维下标 `mid`，对应到二维矩阵中的位置为：

```cpp
int row = mid / n;
int col = mid % n;
```

因此取值就是：

```cpp
matrix[mid / n][mid % n]
```

代码：

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size();
        int n = matrix[0].size();

        int left = 0;
        int right = m * n - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            int row = mid / n;
            int col = mid % n;
            int value = matrix[row][col];

            if (value == target) {
                return true;
            } else if (value < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return false;
    }
};
```

核心理解：

```text
二维矩阵
↓
逻辑上拉成一维有序数组
↓
普通二分
↓
mid / n 得到行
mid % n 得到列
```

易错点：这种方法要求矩阵整体拉直以后仍然有序，也就是不仅每行递增，还必须满足“下一行行首 > 上一行行尾”。不能直接套到普通的行列有序二维矩阵上。

时间复杂度 `O(log(m * n))`，额外空间 `O(1)`。

### 2. 33. 搜索旋转排序数组

旋转数组虽然整体已经不再有序，但每次二分取出 `mid` 后，左右两部分中至少有一边一定仍然有序。

因此相比普通二分，只多了一步：

```text
先判断哪一半有序
↓
再判断 target 是否位于这一段有序区间
↓
决定保留左边还是右边
```

如果：

```cpp
nums[left] <= nums[mid]
```

说明 `[left, mid]` 有序。

这时检查：

```cpp
nums[left] <= target && target < nums[mid]
```

如果成立，说明答案位于左边：

```cpp
right = mid - 1;
```

否则：

```cpp
left = mid + 1;
```

如果左边不是有序区间，那么右半边一定有序，再判断：

```cpp
nums[mid] < target && target <= nums[right]
```

完整代码：

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                return mid;
            }

            // 左半边有序
            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            }

            // 右半边有序
            else {
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }

        return -1;
    }
};
```

这题最关键的一句话：

> 普通二分直接根据 `nums[mid]` 和 `target` 判断方向；旋转数组二分需要先确定哪一半有序，再利用这个有序区间判断 target 在哪边。

时间复杂度 `O(log n)`，额外空间 `O(1)`。

### 3. 34. 在排序数组中查找元素的第一个和最后一个位置

这题不能在第一次找到 `target` 时直接返回，因为当前 `mid` 可能只是众多 `target` 中的某一个。

核心方法是做两次二分：

```text
第一次：寻找最左边的 target
第二次：寻找最右边的 target
```

找左边界时，如果：

```cpp
nums[mid] == target
```

先记录：

```cpp
ans = mid;
```

但不停止，而是继续：

```cpp
right = mid - 1;
```

因为左边可能还存在另一个 `target`。

找右边界正好反过来：

```cpp
ans = mid;
left = mid + 1;
```

代码：

```cpp
class Solution {
public:
    int findLeft(vector<int>& nums, int target) {//左边界
        int left = 0;
        int right = nums.size() - 1;
        int ans = -1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] < target) {
                left = mid + 1;
            } else if (nums[mid] > target) {
                right = mid - 1;
            } else {
                ans = mid;
                right = mid - 1;
            }
        }

        return ans;
    }

    int findRight(vector<int>& nums, int target) {//右边界
        int left = 0;
        int right = nums.size() - 1;
        int ans = -1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] < target) {
                left = mid + 1;
            } else if (nums[mid] > target) {
                right = mid - 1;
            } else {
                ans = mid;
                left = mid + 1;
            }
        }

        return ans;
    }

    vector<int> searchRange(vector<int>& nums, int target) {
        return {
            findLeft(nums, target),
            findRight(nums, target)
        };
    }
};
```

可以把普通二分和边界二分放在一起记：

```text
普通二分：
找到 target → return

找左边界：
找到 target → 记录答案 → 继续向左

找右边界：
找到 target → 记录答案 → 继续向右
```

它和标准库中的思想也对应：

```text
lower_bound(target) = 第一个 >= target 的位置
upper_bound(target) = 第一个 > target 的位置
```

所以理论上：

```text
左边界 = lower_bound(target)
右边界 = upper_bound(target) - 1
```

时间复杂度为两次 `O(log n)`，总体仍然是 `O(log n)`；额外空间 `O(1)`。

### 4. 153. 寻找旋转排序数组中的最小值

这题和“搜索旋转排序数组”属于同一类旋转数组二分题，但目标不是寻找某一个 `target`，而是寻找旋转后的断点，也就是最小值所在位置。

核心判断可以直接利用 `nums[mid]` 和 `nums[right]`：

```cpp
if (nums[mid] > nums[right])
```

说明最小值一定在 `mid` 右边，因为 `mid` 还处在旋转前较大的那一段：

```cpp
left = mid + 1;
```

否则：

```cpp
nums[mid] <= nums[right]
```

说明 `mid` 到 `right` 这一段有序，并且 `mid` 本身仍然可能就是最小值，所以：

```cpp
right = mid;
```

这里不能写成：

```cpp
right = mid - 1;
```

因为这样可能把真正的最小值 `mid` 排除掉。

代码：

```cpp
class Solution {
public:
    int findMin(vector<int>& nums) {
        int left = 0;
        int right = nums.size() - 1;

        while (left < right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] > nums[right]) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        return nums[left];
    }
};
```

这里使用：

```cpp
while (left < right)
```

**貌似这么多二分查找的题中，目前遇到的只有这个是left<right，其他都是left<=right**

最后把区间压缩到一个元素，此时：

```cpp
left == right
```

就是最小值位置。

时间复杂度 `O(log n)`，额外空间 `O(1)`。


### 5. 155. 最小栈

普通栈能够 `O(1)` 完成 `push`、`pop` 和 `top`，但如果直接寻找当前最小值，需要遍历整个栈，会变成 `O(n)`。

解决办法是额外维护一个辅助栈：

```cpp
stack<int> stk;
stack<int> minStk;
```

`stk` 保存所有正常元素；`minStk` 只保存当前最小值的变化历史。

入栈时：

```cpp
stk.push(val);

if (minStk.empty() || val <= minStk.top()) {
    minStk.push(val);
}
```

这里必须使用：

```cpp
<=
```

而不能只写 `<`，因为可能出现重复最小值。

例如：

```text
push 5
push 3
push 3
```

必须让：

```text
minStk = [5, 3, 3]
```

否则弹出一个 `3` 后，就会错误地认为最小值恢复成 `5`。

出栈时：

```cpp
if (stk.top() == minStk.top()) {
    minStk.pop();
}

stk.pop();
```

代码：

```cpp
class MinStack {
    stack<int> stk;
    stack<int> minStk;

public:
    MinStack() {}

    void push(int val) {
        stk.push(val);

        if (minStk.empty() || val <= minStk.top()) {
            minStk.push(val);
        }
    }

    void pop() {
        if (stk.top() == minStk.top()) {
            minStk.pop();
        }

        stk.pop();
    }

    int top() {
        return stk.top();
    }

    int getMin() {
        return minStk.top();
    }
};
```

核心模型：

```text
普通栈：
保存所有元素

辅助栈：
保存“当前最小值的历史”
```

因此 `getMin()` 不需要重新遍历栈，只需要：

```cpp
return minStk.top();
```

`push / pop / top / getMin` 全部为 `O(1)`，最坏空间复杂度 `O(n)`。


### 6. 739. 每日温度

这是第一次正式接触单调栈模型。

如果对于每一天都向右扫描寻找第一个更高温度，最坏复杂度会达到 `O(n²)`。单调栈换了一个思考方向：

> 不再让“过去的每一天主动向未来寻找答案”，而是让“今天的温度帮助之前还没找到答案的天结算”。

栈中保存的是：

```text
还没有找到右边第一个更大元素的下标
```

而不是直接保存温度，因为最终还需要计算两个位置之间的距离：

```cpp
i - k
```

遍历到第 `i` 天时，如果：

```cpp
temperatures[i] > temperatures[stk.top()]
```

说明当前这一天就是栈顶那一天等待的第一个更高温度。

因此：

```cpp
int k = stk.top();
stk.pop();
ans[k] = i - k;
```

这里必须使用 `while` 而不是 `if`，因为当前温度可能一次性解决多个之前等待中的位置。

代码：

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        vector<int> ans(temperatures.size(), 0);
        stack<int> stk;

        for (int i = 0; i < temperatures.size(); i++) {

            while (!stk.empty() &&
                   temperatures[i] > temperatures[stk.top()]) {

                int k = stk.top();
                stk.pop();

                ans[k] = i - k;
            }

            stk.push(i);
        }

        return ans;
    }
};
```

这里非常容易写错成：

```cpp
temperatures[i] > stk.top()
```

但 `stk.top()` 保存的是下标，不是温度，所以必须写：

```cpp
temperatures[i] > temperatures[stk.top()]
```

最终还留在栈中的位置，说明它们右边不存在更高温度。由于 `ans` 一开始已经初始化为 `0`，因此不用再特殊处理。

单调栈模型可以压缩成一句：

> 栈里保存“还没找到右边第一个更大元素”的下标；每出现一个新元素，就不断解决所有比它小的栈顶元素。

时间复杂度 `O(n)`，因为每个元素最多入栈一次、出栈一次；空间复杂度 `O(n)`。

### 7. 215. 数组中的第 K 个最大元素

一开始想到的方法包括排序、大顶堆和 Quickselect。

排序最直接：

```cpp
sort(nums.begin(), nums.end());//升序排列(从小到大排序)
return nums[nums.size() - k];
```

时间复杂度是 `O(n log n)`。

Quickselect 的核心是使用 `partition`：每次确定一个 `pivot` 的最终排名，只继续搜索目标排名所在的那一半，而不需要把整个数组排序。

如果 partition 后规定：

```text
大的在左边 | pivot | 小的在右边
```

那么：

```text
第 1 大 → 下标 0
第 2 大 → 下标 1
...
第 k 大 → 下标 k - 1
```

因此：

```cpp
int target = k - 1;
```

然后根据：

```cpp
pivotIndex == target
pivotIndex > target
pivotIndex < target
```

决定返回、向左搜索还是向右搜索。

不过固定使用端点作为 pivot 时，Quickselect 在极端情况下可能退化为 `O(n²)`；随机 pivot 的常规版本是期望 `O(n)`。

对于目前面试准备，更值得作为常规解法掌握的是：

> **维护大小为 k 的小顶堆。**

代码：

```cpp
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        priority_queue<int, vector<int>, greater<int>> pq;

        for (int x : nums) {
            pq.push(x);

            if (pq.size() > k) {
                pq.pop();
            }
        }

        return pq.top();
    }
};
```

核心逻辑：

```text
始终只保留目前最大的 k 个元素
```

如果候选者超过 `k` 个，就应该淘汰其中最小的那个，所以使用小顶堆。

最终堆中保存：

```text
整个数组最大的 k 个元素
```

而其中最小的那个正好就是：

```text
第 k 大
```

也就是：

```cpp
pq.top()
```

可以记住这个规律：

```text
前 K 大 → 大小为 K 的小顶堆
前 K 小 → 大小为 K 的大顶堆
```

大小为 `k` 的小顶堆时间复杂度 `O(n log k)`，额外空间 `O(k)`。

对于这题目前掌握层次：

```text
sort：会写
大小为 K 的小顶堆：重点掌握
Quickselect：理解 partition + 只搜索一边
复杂三路划分：暂时不要求
```

## 今日小结

- 二分查找开始进入“变形题”阶段。搜索二维矩阵本质是把二维结构映射成一维有序数组；旋转数组则利用“左右至少一边有序”的性质继续二分。
- 边界二分与普通二分最核心的区别是：普通二分找到就返回，而边界二分找到后先记录答案，再继续向左或向右逼近边界。
- 最小栈体现了“用辅助数据结构保存历史状态”的思想，用额外一个栈保存最小值变化历史，从而把 `getMin()` 降为 `O(1)`。
- 每日温度第一次正式接触单调栈：栈保存尚未找到右侧第一个更大元素的下标，由后出现的更大元素统一帮助之前的位置结算答案。
- 第 K 大重点掌握 Top K 堆模型：前 K 大使用大小为 K 的小顶堆，因为需要不断淘汰当前候选集合里最小的元素。
- 8 月 21 日这一批题不只是“刷了 7 道”，实际上集中补到了二分变形、辅助栈、单调栈、堆和 Quickselect 几个重要模型，后续复盘时应重点看模型判断，而不是重新死记整段代码。
