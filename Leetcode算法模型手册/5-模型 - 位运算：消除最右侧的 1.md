### 适用场景

当题目涉及：

- 统计二进制中 1 的个数
- 不断消除二进制中的 1
- 判断/处理最低位的 1
- 要求使用位运算

可以考虑：

```cpp
n & (n - 1)
```
### 核心性质

```
n &= (n - 1);
```

每执行一次，会消除 `n` 二进制表示中最右侧的一个 `1`。

例如：

```
6 = 110

110 & 101 = 100
100 & 011 = 000
```

一共执行 2 次，因此 `6` 的二进制中有 2 个 `1`。

### 思维模型

看到“统计二进制中有多少个 1”，可以思考：

> 能不能每次直接消掉一个 1？

```
int count = 0;

while (n != 0) {
    n &= (n - 1);
    count++;
}
```

循环执行次数就是 `1` 的数量。

### 核心记忆

```
n & (n - 1)
```

→ 消除最右侧的一个 `1`。
