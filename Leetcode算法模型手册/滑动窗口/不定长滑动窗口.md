## 一、模型识别特征

遇到以下关键词时，优先考虑不定长滑动窗口：

- 最长 / 最短
- 连续子数组 / 子串
- 满足某个条件的连续区间
- 需要动态调整区间长度

典型题：

- 无重复字符的最长子串


## 二、核心思想

维护一个满足条件的窗口：
```
[left, right]
```

使用 `right` 不断向右扩展窗口。

当加入新元素后，窗口不满足题目要求：

移动 left  
缩小窗口

直到窗口重新满足条件。

在满足条件时更新答案。

## 三、窗口状态维护

滑动窗口的关键：

> 根据题目要求选择合适的数据结构维护窗口信息。

例如：

### 无重复字符的最长子串

要求：判断当前窗口中是否存在重复字符。

只需要维护字符是否存在：

```
unordered_set<char>
```

原因：

- 不需要统计字符出现次数；
- 只需要 O(1) 判断某个字符是否已经在窗口中；
- 字符种类不固定，使用哈希集合更加灵活。

窗口变化：

加入元素：

```
windows.insert(s[right]);
```

移除元素：

```
windows.erase(s[left]);
```

判断重复：

```
windows.count(s[right])
```

## 四、固定套路

### 1. 右指针扩展窗口

加入 `right` 指向的元素：

```
加入窗口状态
```

尝试扩大窗口。

### 2. 判断窗口是否合法

如果窗口不满足条件：

```
while(窗口不满足条件)
```

不断移动 `left`：

```
移除left元素;

left++;
```

直到恢复合法。

### 3. 更新答案

当前窗口满足条件：

```
更新最大/最小长度
```

## 五、代码模板

```
for(int right = 0; right < n; right++){

    加入right元素;

    while(窗口不满足条件){

        移除left元素;

        left++;

    }

    更新答案;
}
```


## 六、典型题：无重复字符的最长子串

![[Pasted image 20260809205814.png]]

### 思路

维护窗口：

```
[left,right]
```

保证窗口内没有重复字符。

遍历字符串：

1. right 向右移动，新字符加入窗口。
2. 如果新字符已经存在：

不断移动 left，删除窗口左侧字符。

3. 当前窗口合法：

更新最大长度。

## 七、代码模板

```
int lengthOfLongestSubstring(string s) {

    int left = 0;
    int maxLen = 0;

    unordered_set<char> window;

    for(int right = 0; right < s.size(); right++){

        while(window.count(s[right])){

            window.erase(s[left]);
            left++;

        }

        window.insert(s[right]);

        maxLen = max(maxLen, right-left+1);
    }

    return maxLen;
}
```


## 八、记忆口诀

看到：

```
连续区间
+
最长/最短
+
动态满足条件
```

优先考虑：

```
不定长滑动窗口
```

核心：

```
右扩展 + 左收缩 + 维护窗口状态
```

其中：

- 判断是否存在 → `unordered_set`
- 统计出现次数 → `unordered_map`
- 字符范围固定 → `array<int,26>`


另外补充一个小细节：你这里使用 `unordered_set` 是非常典型的“状态设计”。很多初学者做最长无重复子串时会想：

> “我要记录每个字符出现在哪里。”

然后用 `unordered_map<char,int>`。

其实也可以，但这个题只问**最长长度**，不需要知道重复字符的位置，所以 `unordered_set` 已经足够。这也是面试里比较喜欢追问的点：

> 为什么不用 map？为什么用 set？

回答：

> 因为本题只需要判断字符是否存在，不需要记录字符出现次数或者下标，因此使用哈希集合 `unordered_set` 即可满足 O(1) 查询，同时空间复杂度更低。  
> 如果题目要求快速跳转左边界，例如记录字符最新出现位置，则可以使用 `unordered_map<char,int>`。
