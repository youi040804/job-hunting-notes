# 定长滑动窗口

## 一、模型识别特征

遇到以下关键词优先考虑：

- 连续子数组 / 子串
- 窗口长度固定为 k
- 枚举所有长度为 k 的区间
- 统计窗口内元素数量、频率、和等信息

典型题：

- 找到字符串中所有字母异位词

## 二、核心思想

维护一个长度固定为 k 的窗口。

窗口右端不断向右移动，每次只需要：

1. 新元素进入窗口
2. 根据窗口状态更新答案
3. 左端元素离开窗口

不需要每次重新遍历整个窗口。

因为每个元素最多进入窗口一次，离开窗口一次，所以时间复杂度通常为 O(n)。


## 三、定长滑动窗口三部曲：入 → 更新答案 → 出

### 1. 入

右端元素进入窗口：
```
cnt[s[right]]++;
```

更新窗口状态。


### 2. 更新答案

当窗口长度达到 k：

```
[right-k+1, right]
```

根据题目要求判断。

例如字母异位词：

比较当前窗口字符频率和目标字符串频率是否一致。

### 3. 出

左端元素离开窗口：

```
cnt[s[left]]--;
```

为下一次移动准备。


## 四、代码模板

```
for(int right=0; right<n; right++){

    加入right元素;//①入

    int left = right-k+1;

    if(left < 0)
        continue;

    更新答案;//②更新

    移除left元素;//③出
}
```


## 五、典型题：找到字符串中所有字母异位词

![[Pasted image 20260809204846.png]]

### 思路

p 的异位词满足：

- 长度相同
- 每个字符出现次数相同

因此：

1. 统计 p 的字符频率
2. 使用长度为 p.size() 的滑动窗口遍历 s
3. 比较窗口字符频率和 p 是否一致

由于只有小写字母：

```
array<int,26>
```

比哈希表更合适。


## 六、记忆口诀

固定长度 k：

```
入 → 更新答案 → 出
```

看到：

```
连续 + 固定长度
```

优先想到定长滑动窗口。

一个值得注意的点：`std::array` 支持直接比较
```
array<int,26>cnt_p;
array<int,26>cnt_s;
if(cnt_s==cnt_p){
	ans.push_back(left);//更新
}
```
因为`std::array` 重载了 `==` 运算符，它会**逐元素比较**两个数组。
```
// 实际等效于：
bool operator==(const array& a, const array& b) {
    for (size_t i = 0; i < a.size(); ++i) {
        if (a[i] != b[i]) return false;
    }
    return true;
}
```
`std::vector` 也支持直接比较。
