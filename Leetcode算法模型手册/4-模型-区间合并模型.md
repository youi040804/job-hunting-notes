### 二、核心思想

区间问题最大的问题：

不知道未来还有多少区间会加入当前范围。

所以维护：

```
当前合并区间
```

尤其关注：

```
右边界 end
```

因为右边界决定：

后面的区间是否还能进入。

### 三、通用模板

```
sort(intervals.begin(), intervals.end());

vector<vector<int>> ans;

int start=intervals[0][0];
int end=intervals[0][1];

for(auto interval: intervals)
{
    if(interval[0]<=end)
    {
        end=max(end,interval[1]);
    }
    else
    {
        ans.push_back({start,end});

        start=interval[0];
        end=interval[1];
    }
}


ans.push_back({start,end});
```
