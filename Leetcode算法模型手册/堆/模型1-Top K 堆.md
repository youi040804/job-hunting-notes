### 适用场景

当题目出现：

- 第 K 大
- 第 K 小
- 前 K 大
- 前 K 小
- 数据量较大，不希望完整排序

需要考虑维护大小为 K 的堆。

### 核心思想

寻找前 K 大：

```
只维护当前最大的 K 个元素
```

候选元素超过 K 个时，需要淘汰：

```
这 K+1 个元素中最小的那个
```

因此使用：

```
小顶堆
```

### 前 K 大

```
priority_queue<int,vector<int>,greater<int>> pq;

for (int x : nums) {
    pq.push(x);

    if (pq.size() > k) {
        pq.pop();
    }
}
```

遍历结束以后，堆中就是：

```
整个数组最大的 K 个元素
```

而：

```
pq.top()
```

是这 K 个元素中最小的，因此就是第 K 大。

### 反直觉规律

```
前 K 大
→ 小顶堆

前 K 小
→ 大顶堆
```

原因不是为了快速取得答案本身，而是为了快速淘汰“不合格候选人”。

```
维护前 K 大
→ 淘汰最小值
→ 小顶堆

维护前 K 小
→ 淘汰最大值
→ 大顶堆
```

### 复杂度

堆最多只有 K 个元素。

单次 push / pop：

```
O(log K)
```

遍历 N 个元素：

```
O(N log K)
```

额外空间：

```
O(K)
```
