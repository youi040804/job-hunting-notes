### 识别

出现：

- 链表排序；
- 要求 O(nlogn)；
- 不希望转换成数组。

### 为什么使用归并排序？

链表：

- 无法随机访问；
- 不适合快速排序；
- 不适合堆排序。

但是：

链表非常适合：

- 找中点；
- 修改 next 指针；
- 合并有序链表。

### 核心流程

无序链表
↓
快慢指针找中点
↓
断开成两个链表
↓
递归排序左右链表
↓
merge两个有序链表
↓
得到结果

### 两个核心模板

找中点：
```
slow=head;
fast=head;

while(fast&&fast->next){
    slow=slow->next;
    fast=fast->next->next;
}

```

合并：
```
while(head1&&head2){
    比较节点值
    cur连接较小节点
}

```
