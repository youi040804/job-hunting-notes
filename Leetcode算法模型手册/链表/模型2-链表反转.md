# 算法模型手册：链表反转

## 模型识别特征

- 原地反转单链表；
- 需要改变节点之间的 `next` 指向；
- 要求 O(1) 额外空间。

## 核心思想

维护三个角色：

- `pre`：已反转部分的头；
- `cur`：当前待处理节点；
- `temp`：暂存原链表的下一个节点。

先保存 `cur->next`，再反转当前指针方向。

## 模板

```cpp
ListNode* pre = nullptr;
ListNode* cur = head;

while (cur != nullptr) {
    ListNode* temp = cur->next;
    cur->next = pre;
    pre = cur;
    cur = temp;
}

return pre;
```

## 易错点

- 必须先保存 `temp`（即cur->next)，否则会丢失后续链表；
- 最终返回 `pre`，不是 `cur`；
- 空链表和单节点链表也能直接适用。
