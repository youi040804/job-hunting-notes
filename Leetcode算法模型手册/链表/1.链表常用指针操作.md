# 链表常用指针操作

## 一、模型识别特征


遇到以下情况，优先考虑链表指针操作：

- 需要删除链表节点；

- 可能修改原头结点；

- 查找倒数第 k 个节点；

- 相邻节点交换；

- 反转整个链表或某一区间；

- 题目要求 O(1) 额外空间。

  
## 二、哨兵节点 dummy

### 作用

在原头结点前增加一个虚拟节点：

```
ListNode dummy(0, head);
```
这样原头结点也有前驱节点，可以统一处理：

- 删除头结点；
- 交换第一组节点；
- 反转从第一个节点开始的区间；
- 返回修改后的新头结点。

### 使用规则

```
ListNode dummy(0, head);
ListNode* p = &dummy;

// 操作链表
return dummy.next;
```

`dummy` 是对象，使用 `.`；`p` 是指针，使用 `->`。
## 三、固定间距双指针

### 适用

- 删除倒数第 n 个节点；
- 查找倒数第 n 个节点；
- 两指针保持固定距离的问题。

### 核心思想

右指针先走 n 步，再让左右指针一起移动。

当右指针到达链表末尾时，左指针到达目标位置或目标前驱位置。
```
ListNode* left = &dummy;
ListNode* right = &dummy;

while (n--) {
    right = right->next;
}

while (right->next) {
    left = left->next;
    right = right->next;
}
```

此时 `left->next` 为倒数第 n 个节点，left为倒数第n个节点的前驱节点。

## 四、局部交换与局部反转

### 通用原则

修改 `next` 前，先保存后续节点：

```
ListNode* nxt = cur->next;
```

否则修改指向后，可能无法继续访问剩余链表。

### 两两交换

局部结构：
```
node0 -> node1 -> node2 -> node3
```

交换后：
```
node0 -> node2 -> node1 -> node3
```
### 区间反转

反转 `[left, right]` 时：

1. 找到 `left` 前一个节点 `p0`；
2. 反转 `right - left + 1` 个节点；
3. 原区间头节点连接反转后的后续节点；
4. `p0` 连接新的区间头节点。

## 五、易错点

- 涉及删除、交换、反转头结点时，优先加 dummy；
- 链表指针改动前先保存 `next`；
- 注意循环次数：区间 `[left, right]` 长度为 `right - left + 1`；
- 固定间距双指针中，右指针先走几步取决于左右指针的初始位置；
- 链表题不要把长链表直接转换为整数，可能溢出，应逐位模拟计算。
