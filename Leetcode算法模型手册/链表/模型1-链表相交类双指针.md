## 模型识别特征

- 两条单链表；
- 寻找第一个公共节点/相交节点；
- 不能使用额外哈希表，要求 O(1) 空间。

## 核心思想

两个指针分别走：

```cpp
A链表 + B链表
B链表 + A链表
```

两者总路程相同，因此会在相交节点相遇；若不相交，则同时到达 `nullptr`。

## 模板

```cpp
ListNode* p = headA;
ListNode* q = headB;

while (p != q) {
    p = p ? p->next : headB;
    q = q ? q->next : headA;
}

return p;
```

## 易错点

- 比较节点指针是否相同，不是比较节点值；
- 不相交时返回的是 `nullptr`；
- 不需要提前计算链表长度。
