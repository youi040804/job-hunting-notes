### 识别

出现：

- 链表节点包含多个指针；
- 指针可能指向任意位置；
- 要求复制一个完全独立的数据结构。

例如：

- 随机链表复制；
- 克隆图；
- 复杂树复制。

### 核心思想

普通复制：

节点

 |

next

 |

下一个节点

只需要顺序创建。

复杂结构：

节点A

 |

random

 ↓

节点C

创建 A 时，可能还没有创建 C。

因此需要：

第一阶段：

创建所有节点，并建立：

旧节点 -> 新节点

第二阶段：

恢复节点之间的引用关系。

### 通用模板

```
unordered_map<Node*, Node*> mp;

// 第一遍：创建节点
while(cur){
    mp[cur]=new Node(cur->val);
    cur=cur->next;
}

// 第二遍：连接关系
while(cur){
    mp[cur]->next=mp[cur->next];
    mp[cur]->random=mp[cur->random];
    cur=cur->next;
}
```
