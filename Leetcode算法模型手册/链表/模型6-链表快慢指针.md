## 模型：链表快慢指针

### 识别

出现：

- 判断链表是否有环；
- 找链表中点；
- 链表分割；
- 链表左右部分处理。

### 核心思想

利用两个速度不同的指针：

slow：一次一步

fast：一次两步

通过速度差解决链表无法随机访问的问题。

### 常见应用

### 1. 找链表中点

模板：
```
slow=head;
fast=head;

while(fast&&fast->next){
    slow=slow->next;
    fast=fast->next->next;
}
```

结束后：

- slow 指向中点附近。

### 2. 判断链表是否有环

模板：
```
while(fast&&fast->next){
    slow=slow->next;
    fast=fast->next->next;
    
    if(slow==fast)
        return true;
}
return false;
```

理解：
如果存在环，快指针最终一定会追上慢指针。

### 3. 链表分割

例如排序链表：

1 -> 2 -> 3 -> 4

找到中点：

1 -> 2
3 -> 4

然后分别处理两个子链表。
