### 识别

出现：

- 缓存；
- 最近使用；
- 淘汰最久未使用；
- 要求 O(1)。
### 核心问题

需要同时满足：

1. 根据 key 快速找到数据。

需要：unordered_map

2. 根据访问顺序快速调整。

需要：双向链表

### 数据结构

unordered_map

key
↓
Node*
↓
双向链表


节点保存：

key

value

prev

next


### 链表规则

头部：最近使用

尾部：最久未使用


访问：
```
删除当前位置
加入头部
```

淘汰：

删除tail前节点


### 操作模板

get：
```
map查找节点

不存在:
return -1

存在:
移动到头部
返回value
```

put：

```
key存在:
修改value
移动头部

key不存在:
创建节点
加入头部

超过容量:
删除尾部

```
