### 一、识别特征

遇到：

- 每个位置需要知道前面或者后面的信息
- 不希望重复计算
- 可以通过一次遍历保存历史状态

例如：

- 除自身以外数组乘积
![[Pasted image 20260810164221.png]]


- 区间累计和
- 连续元素统计

### 二、核心思想

不要针对每个位置重新计算。

例如：

暴力：

```
nums[i]
重新计算左边和右边
```

复杂度：

```
O(n²)
```

优化：

提前保存：

```
前缀信息
```
和：
```
后缀信息
```

当前位置直接组合。

模板：

```
result[i]=prefix[i]*suffix[i]
```

或者：

```
result[i]=prefix[i]+suffix[i]
```

### 三、通用模板

```
vector<int> result(n);

保存左侧信息：

for(int i=1;i<n;i++)//注意左边的起始位置
{
    result[i]=result[i-1]+nums[i-1];
}


保存右侧信息：

int temp=0;

for(int i=n-2;i>=0;i--)//注意右边的起始位置
{
    temp+=nums[i+1];
    result[i]+=temp;
}
```
