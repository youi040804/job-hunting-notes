适用场景：
看到：
- 字母异位词
- 忽略字符顺序
- 判断字符组成是否一致

第一反应：
```
排序！
```
因为：
```
eat
tea
ate
```

排序以后：
```
aet
```
完全一致。
于是：
```
unordered_map<string,vector<string>>
```

即可完成分组。

复杂度：

```
O(n × klogk)
```

其中：

k 为字符串长度。
