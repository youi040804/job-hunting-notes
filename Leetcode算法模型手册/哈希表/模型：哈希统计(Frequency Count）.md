### 识别特征

看到下面这些关键词，优先考虑统计频率：

- 统计元素出现次数
- 比较两个集合（字符串）的出现频率
- 判断字符组成是否一致
- 判断是否为异位词（Anagram）
- 找众数、重复元素、Top K 高频元素等

---

### 思考顺序

**第一步：是否需要统计每种元素出现次数？**

如果需要，优先考虑"频率统计"。

↓

**第二步：元素种类是否固定？**

- 固定（如 26 个小写字母、128 个 ASCII 字符）
  → 使用数组。

- 不固定（任意整数、字符串、Unicode 字符等）
  → 使用哈希表（`unordered_map`）。

↓

**第三步：统计完成后如何利用频率？**

常见有三种用途：

1. 比较两个频率表是否相同
2. 根据频率进行分组
3. 根据频率进行排序或筛选（Top K）

### 常见数据结构

```cpp
// 字符集固定
int cnt[26];

// 任意整数
unordered_map<int, int> cnt;

// 任意字符串
unordered_map<string, int> cnt;
```

### 易错点

- 字符集固定时，不要第一时间使用 `unordered_map`，数组速度更快、空间更省。
- 如果只是判断两个字符串是否为异位词，数组统计通常比排序更优（时间复杂度 O(n)）。
- 如果需要把所有异位词分组，则通常使用"排序后的字符串"作为哈希表 Key，更容易实现。

### 子模型：规范化（Canonical Key）

**识别特征**

多个对象本质相同，只是表现形式不同。

例如：

- 字母顺序不同
- 大小写不同
- 表达形式不同

目标：把它们转换成统一表示，再作为哈希表 Key。


常见做法

- 排序字符串作为 Key（字母异位词分组）
- 全部转小写
- 去掉空格、标点
- 统计频率后编码成字符串作为 Key（进阶做法）


口诀
**先规范，再哈希。**
