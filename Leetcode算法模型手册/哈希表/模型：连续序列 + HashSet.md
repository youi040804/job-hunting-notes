适用场景：
看到：
- 连续数字
- O(n)
- 判断元素是否存在

第一反应：

```
unordered_set
```

流程：

第一步：全部放入 HashSet。

第二步：只从起点开始统计。

判断：

```
num-1 是否存在
```

不存在：

说明：当前数字就是起点。

随后：

```
while(hashSet.contains(curr))
```

一直向后统计。

为什么不用排序？

排序：

```
O(nlogn)
```

题目要求：

```
O(n)
```

所以只能HashSet。


注意：
不要遍历：

```
nums
```

要遍历：

```
hashSet
```

否则：

重复数字会导致重复统计。

这是这道题最容易踩的坑。
