看到以下关键词时考虑该模型：

- 所有子集
- 幂集
- 所有可能组合

核心代码结构：

```
选择
递归
撤销选择
```

其中 `startIndex` 用于保证下一层只从后面的元素继续选择，避免重复选择前面的元素。
## 3. 数组的所有子集 / 幂集

### 题目

给定一个元素互不相同的数组，输出所有可能的子集。

例如：

 nums = [1,2,3]

所有子集：

```
 []  
 [1]  
 [1,2]  
 [1,2,3]  
 [1,3]  
 [2]  
 [2,3]  
 [3]
```



### 思路：回溯

当前 `path` 本身就是一个合法子集，所以每进入一层递归，先将 `path` 加入结果。

之后从 `startIndex` 开始枚举：

1. 选择当前元素：`push_back`
2. 从下一个位置继续递归
3. 撤销当前选择：`pop_back`
4. for 循环继续选择下一个元素
```cpp

 vector<vector<int>> res;  
 vector<int> path;  
 ​  
 void backtracking(vector<int>& nums, int startIndex) {  
     res.push_back(path);  
 ​  
     for (int i = startIndex; i < nums.size(); i++) {  
         path.push_back(nums[i]);  
 ​  
         backtracking(nums, i + 1);  
 ​  
         path.pop_back();  
     }  
 }  
 ​  
 vector<vector<int>> subsets(vector<int>& nums) {  
     backtracking(nums, 0);  
     return res;  
 }
```

### 回溯过程

以 `[1,2,3]` 为例：

```
 []  
 │  
 ├── [1]  
 │   ├── [1,2]  
 │   │   └── [1,2,3]  
 │   └── [1,3]  
 │  
 ├── [2]  
 │   └── [2,3]  
 │  
 └── [3]
```

核心理解：

> 选一个当前元素 → 搜完所有以它为前缀的子集 → `pop_back()` 撤销选择 → for 循环选择下一个元素。

注意：

 backtracking(nums, i + 1);

只是把 `i + 1` 的值传给下一层作为 `startIndex`，不会修改当前层的 `i`。

当前层真正的 `i++` 发生在当前这一轮 for 循环结束之后。
