### 适用场景

当题目出现：

- 计算 `x^n`
- 指数非常大
- 不能线性连乘
- 希望把幂运算从 `O(n)` 优化到 `O(log n)`

需要考虑快速幂。

### 核心思想

普通计算：

```text
x^n
```

需要把 `x` 连乘大约 `n` 次。

但幂具有：

```text
x^n = x^(n/2) × x^(n/2)
```

因此可以每次直接把指数缩小一半。

如果 `n` 是偶数：

```text
x^n = half × half
```

其中：

```text
half = x^(n/2)
```

如果 `n` 是奇数：

```text
x^n = half × half × x
```

### 递归模板

```cpp
double quickPow(double x, long long n) {
    if (n == 0) {
        return 1.0;
    }

    double half = quickPow(x, n / 2);

    if (n % 2 == 0) {
        return half * half;
    }

    return half * half * x;
}
```

### 思维模型

看到：

```text
x^n
```

不要想：

```text
x × x × x × ...
```

而是想：

```text
指数折半
↓
先算 x^(n/2)
↓
得到 half
```

然后：

```text
偶数 → half × half

奇数 → half × half × x
```

### 负指数

数学上：

```text
x^(-n) = 1 / x^n
```

因此外层把负指数转为正指数：

```cpp
long long N = n;

if (N < 0) {
    N = -N;
    return 1.0 / quickPow(x, N);
}
```

### 易错点

不能直接：

```cpp
n = -n;
```

因为：

```text
INT_MIN = -2147483648
```

取反以后得到：

```text
2147483648
```

超过 `int` 最大范围。

因此应该先：

```cpp
long long N = n;
```

然后再：

```cpp
N = -N;
```

### 复杂度

指数变化：

```text
n
↓
n / 2
↓
n / 4
↓
n / 8
↓
...
↓
0
```

因此：

```text
时间复杂度 O(log n)
递归栈空间 O(log n)
```
