### 2.1 快慢双指针-原地修改 / 删除类

#### 一、模型识别特征

遇到以下关键词时，优先考虑快慢双指针：

- 数组原地修改
- 删除元素
- 移除重复元素
- 保持元素相对顺序
- 不允许额外数组空间
- 返回修改后的有效长度
- O(1) 空间复杂度

常见题型：
- 删除指定元素；
- 删除重复元素；
- 保留元素出现次数限制；
- 移动元素到数组某一侧。
#### 二、核心思想
快慢双指针使用两个方向相同的指针：
##### fast 指针

职责：
- 遍历原始数组；
- 寻找满足条件的元素；
- 负责探索未知区域。
##### slow 指针

职责：
- 维护已经处理完成的有效区域；
- 指向下一个应该放置元素的位置；
- 代表当前答案状态，而不是原数组当前位置。

核心理解：

> slow 后面的区域不是答案的一部分，可以被覆盖。

因此这类题实际上不是“删除元素”，而是：

> 将需要保留的元素覆盖到数组前方。

#### 三、基础模型：保留满足条件的元素

适用：LeetCode 27 删除元素。
例如：删除数组中的指定元素：
```text
[3,2,2,3]

删除3

结果：

[2,2]
```

思路：fast 遍历所有元素。

如果当前元素需要保留：

```cpp
nums[slow] = nums[fast];
slow++;
```

模板：

```cpp
int slow = 0;

for (int fast = 0; fast < nums.size(); fast++) {

    if (nums[fast] != target) {
        nums[slow++] = nums[fast];
    }

}

return slow;
```

#### 四、进阶模型：有序数组去重

适用：LeetCode 26 删除有序数组中的重复项。

特点：数组已经排序。

因此：相同元素一定连续出现。

判断：
```cpp
nums[fast] != nums[slow]
```

流程：
1. slow 指向当前结果数组最后一个元素；
2. fast 向后寻找新的不同元素；
3. 找到后移动 slow，并覆盖。

模板：

```cpp
int slow = 0;

for (int fast = 1; fast < nums.size(); fast++) {

    if (nums[fast] != nums[slow]) {
        nums[++slow] = nums[fast];
    }

}

return slow + 1;
```

#### 五、进阶模型：限制元素最多出现 k 次

适用：LeetCode 80 删除有序数组中的重复项 II。

核心思想：维护：
```text
前 curr_size 个元素一定满足题目要求
```

因为要求最多出现 k 次：
判断：
```cpp
nums[i] != nums[curr_size - k]
```

原因：
如果当前元素等于结果数组倒数第 k 个元素：
说明加入后会导致该元素出现次数超过 k 次。

例如：
##### 最多出现两次

判断：

```cpp
nums[i] != nums[curr_size - 2]
```

##### 最多出现三次

判断：

```cpp
nums[i] != nums[curr_size - 3]
```

通用模板：

```cpp
int curr_size = k;

for (int i = k; i < nums.size(); i++) {

    if (nums[i] != nums[curr_size - k]) {
        nums[curr_size++] = nums[i];
    }

}

return curr_size;
```

#### 六、面试表达

遇到原地修改类双指针问题，可以这样回答：

> 由于题目要求原地修改并且空间复杂度为 O(1)，不能创建新的数组，因此采用快慢双指针。快指针负责遍历原数组寻找满足条件的元素，慢指针维护已经构造完成的有效区域。当找到符合条件的元素时，将其覆盖到慢指针位置。最终慢指针记录的就是修改后的有效长度。

如果涉及出现次数限制：

> 对于最多保留 k 次的情况，只需要判断当前元素是否等于结果区域倒数第 k 个元素。如果相同，说明加入后会超过限制，否则将其加入结果区域。

#### 七、易错点

##### 1. 不要理解为真正删除

数组没有发生长度变化。

实际过程：

```text
寻找有效元素

↓

覆盖无效区域

↓

返回有效长度
```

##### 2. slow 维护的是答案状态

错误理解：

> slow 是慢速移动的 fast。

正确理解：

> slow 指向已经构造完成的有效区域。

##### 3. 判断重复次数时，根据限制 k 调整

保留 1 个：

```cpp
slow
```

保留 k 个：

```cpp
curr_size - k
```
