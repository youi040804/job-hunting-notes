## 模型识别特征

关键词：

- 两个有序数组合并
- 原地修改
- 后面有空位


## 核心思想

不要从前往后：

因为会覆盖原数据。

从后往前：

```
p = m+n-1
```

三个指针：

```
p1 -> nums1有效元素末尾

p2 -> nums2末尾

p -> 最终数组末尾
```

---

## 模板

```
while(p2>=0){

    if(p1>=0 && nums1[p1]>nums2[p2])
        nums1[p--]=nums1[p1--];

    else
        nums1[p--]=nums2[p2--];

}
```
