## 一、有序数组对撞双指针模型

### 一、模型识别特征

遇到以下关键词优先考虑：

- 数组已经排序
- 查找两个数满足某种关系
- O(1)空间要求
- 原地修改
- 寻找最大/最小范围

例如：

- 两数之和 II

- 盛最多水的容器
![[Pasted image 20260809203804.png]]

- 合并两个有序数组
![[Pasted image 20260809203838.png]]

## 二、核心思想

利用数组有序后的单调性。

左右指针分别位于数组两端：

```
left ---------------- right
```

根据当前状态决定移动哪一个指针。

如果当前结果偏小：

```
left++
```

尝试增大结果。

如果当前结果偏大：

```
right--
```

尝试减小结果。


## 三、思考流程

遇到问题时：

1. 是否有排序信息？

如果：

```
是
```

考虑双指针。

2. 当前结果和目标有什么单调关系？

例如：

两数之和：

```
sum < target
```

说明：

```
左边太小
```

移动：

```
left++
```

3. 是否要求原地修改？

如果是：考虑从后往前处理，避免覆盖已有数据。

## 四、模板

### 两数之和 II

```
int left = 0;
int right = nums.size()-1;

while(left < right){

    int sum = nums[left]+nums[right];

    if(sum == target){
        return {left+1,right+1};
    }
    else if(sum < target){
        left++;
    }
    else{
        right--;
    }
}
```

# 二、容器类双指针模型

## 模型识别特征

关键词：

- 最大面积
- 两端距离
- 高度由短板决定

例如：

```
最大水容量
```

## 核心思想

面积：

```
(right-left)*min(height[left],height[right])
```

宽度一定随着移动减少。

因此：

如果移动长板：

```
高度不会增加
宽度一定减少
```

不可能得到更优答案。

所以：

只能移动短板。

## 模板

```
while(left < right){

    更新答案;

    if(height[left] < height[right])
        left++;
    else
        right--;

}
```

# 三、三数之和模型

## 1、模型识别特征

关键词：

- 三个数
- 和为目标值
- 不重复组合
- 排序后可以利用单调性

三数之和本质上可以转换成：

```text
固定一个数 + 两数之和
```

也就是先固定 `nums[k]`，再在右侧区间中使用对撞双指针寻找另外两个数。

## 2、核心思想

第一步先排序：

```cpp
sort(nums.begin(), nums.end());
```

然后依次固定一个数字：

```cpp
nums[k]
```

剩余区间使用左右双指针：

```text
k    left              right
↓     ↓                   ↓
-4   -1   -1   0   1   2
```

当前三个数的和为：

```cpp
sum = nums[k] + nums[left] + nums[right];
```

根据 `sum` 和目标值之间的关系移动指针：

```text
sum < target
    left++

sum > target
    right--

sum == target
    保存答案
    left++
    right--
```

因为数组已经排序，所以：

- 当前和太小，需要让较小的数变大，因此移动 `left`；
- 当前和太大，需要让较大的数变小，因此移动 `right`。

这样就把原本三层枚举的 `O(n^3)` 降到了 `O(n^2)`。

## 3、去重

三数之和最容易出错的地方是去重。

去重的真正目的不是：

```text
看到重复数字就跳过
```

而是：

> 防止同一个三元组被重复加入答案。

排序除了提供双指针需要的单调性之外，还有一个作用：**让相同数字相邻，从而方便去重。**

三数之和主要有两层去重。

### (1) 固定值 `k` 去重

```cpp
if (k > 0 && nums[k] == nums[k - 1]) {
    continue;
}
```

如果当前固定值和前一个固定值相同，那么前一个位置已经搜索过所有以这个数作为固定值的组合。

继续搜索只会产生重复答案，所以直接跳过。

例如：

```text
[-1, -1, 0, 1, 2]
 ↑
第一次固定 -1：已经搜索所有以 -1 开头的组合

     ↑
第二次再固定 -1：会产生重复组合
```

所以固定值的判断可以理解成：

```text
这个固定值以前用过没有？
```


### (2) 找到答案后对 `left/right` 去重

当：

```cpp
sum == target
```

说明当前三个数已经组成一个合法答案。

保存答案以后，需要跳过左右两侧连续的重复值：

```cpp
while (left < right && nums[left] == nums[left + 1]) {
    left++;
}

while (left < right && nums[right] == nums[right - 1]) {
    right--;
}
//先去重，再移动 
left++;
right--;
```

原因是当前 `left/right` 对应的值已经组成过答案。

如果旁边还是相同的值，继续使用它们只会得到相同的三元组。

可以理解成：

```text
left/right 去重：

这个答案里的左右值刚刚已经用过没有？
```

## 4、为什么 `sum < target` / `sum > target` 时可以不去重？

例如：

```text
sum < target
    left++

sum > target
    right--
```

这两种情况下还没有向结果集中加入答案，因此即使下一个数字和当前数字相同，也不会产生重复答案。

最多只是重复进行一次相同的判断。

所以这里进行去重属于：

```text
可选优化
```

而不是保证答案正确所必需的操作。

真正必须重点处理的是：

```text
固定值 k 去重

以及

找到答案以后 left/right 去重
```


## 5、完整模板

```cpp
sort(nums.begin(), nums.end());

for (int k = 0; k < n - 2; k++) {

    // 固定值去重
    if (k > 0 && nums[k] == nums[k - 1]) {
        continue;
    }

    int left = k + 1;
    int right = n - 1;

    while (left < right) {

        int sum = nums[k] + nums[left] + nums[right];

        if (sum < target) {
            left++;
        }
        else if (sum > target) {
            right--;
        }
        else {
            // 保存答案
            res.push_back({nums[k],nums[left],nums[right]});
            
            // left 去重
            while (left < right && nums[left] == nums[left + 1]) {
                left++;
            }

            // right 去重
            while (left < right && nums[right] == nums[right - 1]) {
                right--;
            }
            
            //先去重，再移动 
            left++;
            right--;
        }
    }
}
```

## 6、一句话记忆

```text
三数之和
= 排序
+ 固定一个数
+ 剩余区间两数之和
+ 两层去重
```

其中去重记成：

```text
k 去重：
这个固定值以前用过没有？

left/right 去重：
这个答案里的左右值刚刚已经用过没有？
```

复杂度：

```text
时间：O(n²)
空间：O(1)（不考虑排序内部空间和返回结果）
```
