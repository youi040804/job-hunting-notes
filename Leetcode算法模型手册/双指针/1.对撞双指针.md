## 一、有序数组对撞双指针模型

### 一、模型识别特征

遇到以下关键词优先考虑：

- 数组已经排序
- 查找两个数满足某种关系
- O(1)空间要求
- 原地修改
- 寻找最大/最小范围

例如：

- 两数之和 II
![[Pasted image 20260809203658.png]]

- 盛最多水的容器
![[Pasted image 20260809203804.png]]

- 合并两个有序数组
![[Pasted image 20260809203838.png]]

## 二、核心思想

利用数组有序后的单调性。

左右指针分别位于数组两端：

```
left ---------------- right
```

根据当前状态决定移动哪一个指针。

如果当前结果偏小：

```
left++
```

尝试增大结果。

如果当前结果偏大：

```
right--
```

尝试减小结果。


## 三、思考流程

遇到问题时：

1. 是否有排序信息？

如果：

```
是
```

考虑双指针。

2. 当前结果和目标有什么单调关系？

例如：

两数之和：

```
sum < target
```

说明：

```
左边太小
```

移动：

```
left++
```

3. 是否要求原地修改？

如果是：考虑从后往前处理，避免覆盖已有数据。

## 四、模板

### 两数之和 II

```
int left = 0;
int right = nums.size()-1;

while(left < right){

    int sum = nums[left]+nums[right];

    if(sum == target){
        return {left+1,right+1};
    }
    else if(sum < target){
        left++;
    }
    else{
        right--;
    }
}
```

# 二、容器类双指针模型

## 模型识别特征

关键词：

- 最大面积
- 两端距离
- 高度由短板决定

例如：

```
最大水容量
```

## 核心思想

面积：

```
(right-left)*min(height[left],height[right])
```

宽度一定随着移动减少。

因此：

如果移动长板：

```
高度不会增加
宽度一定减少
```

不可能得到更优答案。

所以：

只能移动短板。

## 模板

```
while(left < right){

    更新答案;

    if(height[left] < height[right])
        left++;
    else
        right--;

}
```

# 三、三数之和模型

## 模型识别特征

关键词：

- 三个数
- 和为目标值
- 不重复组合

## 核心思想

三数之和：
![[Pasted image 20260809204009.png]]

转换：

```
一个数 + 两数之和
```

步骤：

1. 排序
2. 固定一个数字nums\[k]
3. 剩余两个数字使用双指针nums\[i]和nums\[j]

例如：

```
nums[k]+nums[i]+nums[j]
```

根据结果：

```
sum < target
    i++

sum > target
    j--

sum == target
    保存答案
```

## 注意点

去重：

固定指针：

```
if(nums[k]==nums[k-1])
continue;
```

移动指针：跳过重复元素。
```
while(i<j&&nums[i]==nums[i-1])i++;

while(i<j&&nums[j]==nums[j+1])j--;
```
