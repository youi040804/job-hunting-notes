### 适用场景

当题目出现：

- 原数组本身严格递增
- 数组经过一次旋转
- 要求 `O(log n)`
- 在旋转数组中查找目标值
- 在旋转数组中寻找最小值 / 旋转点

需要考虑旋转数组二分。

### 核心性质

旋转后的数组虽然整体不再有序，但任意取一个 `mid` 后：

> `mid` 左右两部分中，至少有一边一定是有序的。

例如：

```
[4,5,6,7,0,1,2]
```

取：

```
mid = 3
nums[mid] = 7
```

可以看到：

```
[4,5,6,7]
```

这一段仍然有序。

因此旋转数组二分的核心不是直接比较：

```cpp
nums[mid] 和 target
```

而是先判断：

```
哪一边有序？
```

再利用有序区间判断答案是否位于这一边。


### 模型一：在旋转数组中搜索 target

首先正常检查：

```cpp
if (nums[mid] == target) {
    return mid;
}
```

然后判断左半边是否有序：

```cpp
if (nums[left] <= nums[mid])
```

如果成立：

```
[left, mid]
```

就是有序区间。

接下来判断 target 是否处于其中：

```cpp
if (nums[left] <= target && target < nums[mid]) {
    right = mid - 1;
} else {
    left = mid + 1;
}
```

否则说明右半边有序：

```cpp
if (nums[mid] < target && target <= nums[right]) {
    left = mid + 1;
} else {
    right = mid - 1;
}
```

完整骨架：

```cpp
while (left <= right) {
    int mid = left + (right - left) / 2;

    if (nums[mid] == target) {
        return mid;
    }

    // 左半边有序
    if (nums[left] <= nums[mid]) {

        if (nums[left] <= target && target < nums[mid]) {
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }

    // 右半边有序
    else {

        if (nums[mid] < target && target <= nums[right]) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
}
```

### 思维模型

普通二分：

```
看 nums[mid]
↓
直接判断 target 在左还是右
```

旋转数组二分：

```
看 nums[mid]
↓
先确定哪一半有序
↓
判断 target 是否落在这个有序区间
↓
保留可能存在答案的一半
```

可以压缩成一句：

> 先找有序半边，再判断 target 是否属于这个有序区间。


### 模型二：寻找旋转数组最小值

寻找最小值时，不需要 target。

这时可以直接比较：

```cpp
nums[mid]
nums[right]
```

如果：

```cpp
nums[mid] > nums[right]
```

说明 `mid` 位于旋转前较大的那一段。

例如：

```
[4,5,6,7,0,1,2]
       M     R
```

这里：

```
7 > 2
```

说明最小值一定在：

```
mid 右边
```

因此：

```cpp
left = mid + 1;
```

如果：

```cpp
nums[mid] <= nums[right]
```

说明 `[mid, right]` 本身是有序的。

此时最小值可能：

```
就是 nums[mid]
```

也可能还在左侧。

所以：

```cpp
right = mid;
```

注意不能写：

```cpp
right = mid - 1;
```

因为 `mid` 本身可能正是答案。

完整骨架：

```cpp
while (left < right) {
    int mid = left + (right - left) / 2;

    if (nums[mid] > nums[right]) {
        left = mid + 1;
    } else {
        right = mid;
    }
}

return nums[left];
```

### 为什么这里用 `left < right`

因为这一题不是“找到就返回”，而是不断压缩答案所在区间。

最后一定会变成：

```
left == right
```

此时只剩一个候选位置，这个位置就是最小值。


### 两类题的区别

搜索 target：

```
核心比较：
target 和有序区间边界
```

寻找最小值：

```
核心比较：
nums[mid] 和 nums[right]
```

搜索题需要判断：

```
target 属不属于当前有序区间
```

最小值题需要判断：

```
旋转断点位于 mid 左边还是右边
```

### 易错点

#### 1. 判断左边有序要写

```cpp
nums[left] <= nums[mid]
```

而不是只凭感觉判断数组哪边更大。

#### 2. target 的区间边界不要重复包含 mid

前面已经判断：

```cpp
nums[mid] == target
```

所以左有序区间通常写：

```cpp
nums[left] <= target && target < nums[mid]
```

右边写：

```cpp
nums[mid] < target && target <= nums[right]
```

#### 3. 寻找最小值时

```cpp
right = mid;
```

不能轻易改成：

```cpp
right = mid - 1;
```

因为 `mid` 仍然可能是最小值。
