### 适用场景

当题目出现：

- 有序数组
- 查找第一个满足条件的位置
- 查找最后一个满足条件的位置
- 查找 target 的左右边界
- 要求 `O(log n)`

需要考虑边界二分。

### 核心思想

普通二分：

```text
找到 target
→ 直接返回
```

边界二分：

```text
找到 target
→ 先记录答案
→ 不停止
→ 继续向目标边界搜索
```

### 查找左边界

```cpp
if (nums[mid] < target) {
    left = mid + 1;
}
else if (nums[mid] > target) {
    right = mid - 1;
}
else {
    ans = mid;
    right = mid - 1;
}
```

找到 target 后继续向左。

### 查找右边界

```cpp
if (nums[mid] < target) {
    left = mid + 1;
}
else if (nums[mid] > target) {
    right = mid - 1;
}
else {
    ans = mid;
    left = mid + 1;
}
```

找到 target 后继续向右。

### 思维模型

不要想着：

> 把所有 target 找出来。

而是：

> 我只寻找最左 / 最右的那个 target，因此找到一个以后，另一侧可以直接排除。

### 与 STL 的关系

```text
lower_bound(target)
→ 第一个 >= target

upper_bound(target)
→ 第一个 > target
```

因此：

```text
左边界 = lower_bound(target)
右边界 = upper_bound(target) - 1
```
