### 适用场景

当题目出现下面条件时，需要考虑摩尔投票：

- 一定存在众数
- 众数出现次数超过 n/2
- 要求 O(n)
- 要求 O(1) 空间

### 核心思想

把众数看成：```+1```

其它数字看成：```-1```

不断进行两两抵消。
由于众数数量大于其它所有数字数量之和，因此无论怎样抵消，最后剩下的一定还是众数。
### 算法流程

维护两个变量：
```
candidate
当前候选人
votes
当前票数
```

遍历数组：
```
如果 votes == 0
    更新候选人为当前元素
如果当前元素 == candidate
    votes++
否则
    votes--
```

遍历结束，candidate 即为众数。
### 思维模型

不要统计所有数字。

而是不断进行：

> 不同元素互相抵消。

只要某个元素数量超过所有其它元素数量之和，它最终一定能够保留下来。

### 面试高频考点

- 为什么能够两两抵消？
- 为什么最后剩下的一定是众数？
- 如果题目不保证存在众数怎么办？
- 如何验证最终结果？

> **补充说明：** 如果题目**不保证一定存在众数**，摩尔投票得到的只是一个候选值，需要再遍历一次数组统计它的出现次数，确认是否真的超过 ⌊n/2⌋。
