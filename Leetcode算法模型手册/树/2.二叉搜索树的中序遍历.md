# 二叉搜索树的中序遍历

## 1. 核心性质

二叉搜索树（BST）满足：左子树全部小于当前节点，右子树全部大于当前节点。因此对 BST 做中序遍历（左 → 中 → 右），得到的节点值序列严格递增。

这个性质常用于：验证一棵树是否为 BST、找第 K 小元素、把 BST 当作有序序列处理。

## 2. 验证 BST：比较中序相邻值

```cpp
class Solution {
    long long pre = LLONG_MIN;

public:
    bool isValidBST(TreeNode* root) {
        if (root == nullptr) return true;
        if (!isValidBST(root->left)) return false;

        if (root->val <= pre) return false;
        pre = root->val;

        return isValidBST(root->right);
    }
};
```

`pre` 始终记录中序遍历中上一个节点值。必须是严格大于，而不是大于等于，因为题目不允许 BST 中出现重复节点值。时间复杂度 `O(n)`，递归栈空间 `O(h)`。

## 3. BST 第 K 小：中序访问计数

中序遍历时，每访问一个真实节点就让 `k--`；当 `k == 0`，当前节点就是第 K 小。

```cpp
int kthSmallest(TreeNode* root, int& k) {
    if (root == nullptr) return -1;

    int left_res = kthSmallest(root->left, k);
    if (left_res != -1) return left_res;

    if (--k == 0) return root->val;

    return kthSmallest(root->right, k);
}
```

这里 `k` 用引用传递，所有递归层共享同一份剩余计数。`-1` 表示“当前子树没有答案”；一旦找到答案，递归结果会被每一层直接 `return`，从而提前结束后续遍历。

实际访问量为到第 K 小节点前的路径和节点数，可写为 `O(h + k)`；但第 K 小可能接近最后一个节点，所以最坏时间复杂度仍为 `O(n)`。额外空间只有递归栈的 `O(h)`。

## 4. 记忆句

> BST 的中序遍历严格递增：用 `pre` 验证大小关系，用 `k` 记录访问到第几个节点。
