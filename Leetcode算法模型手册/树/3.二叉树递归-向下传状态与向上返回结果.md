## 1. 两类常见递归思路

二叉树 DFS 常见有两类：

第一类是**状态从父节点向子节点传递**。当前节点先修改状态，再把新的状态交给左右子树。典型题目：路径总和。

第二类是**左右子树先返回结果，当前节点根据返回值做判断**。典型题目：最近公共祖先。

---

## 2. 向下传状态：路径总和

如果题目描述“从根节点一路往下”，可以考虑把某个状态随着递归向下传递。

例如路径总和：

```cpp
bool hasPathSum(TreeNode* root, int targetSum) {
    if (root == nullptr) return false;

    targetSum -= root->val;

    if (root->left == nullptr && root->right == nullptr) {
        return targetSum == 0;
    }

    return hasPathSum(root->left, targetSum) || hasPathSum(root->right, targetSum);
}
```

这里 `targetSum` 值传递，每个递归分支都有自己的副本，所以左右子树互不影响。

记忆：

> 不同分支应该各算各的 → 值传递很自然。

---

## 3. 向上返回结果：最近公共祖先

最近公共祖先属于后序思维：先递归左右子树，再根据左右返回值决定当前节点返回什么。

```cpp
TreeNode* lowestCommonAncestor(TreeNode* root,TreeNode* p,TreeNode* q) {
    if (root == nullptr) return nullptr;
    if (root == p || root == q) return root;

    TreeNode* left =lowestCommonAncestor(root->left, p, q);
    TreeNode* right =lowestCommonAncestor(root->right, p, q);

    if (left != nullptr && right != nullptr) {
        return root;
    }

    return left != nullptr ? left : right;
}
```

递归返回的非空结果表示“当前子树中找到的有效结果”。它可能是 `p`、`q`，也可能是下层已经确定的最近公共祖先。

判断规则：

```text
当前节点是 p/q      → 返回当前节点
左右都非空          → 当前节点是 LCA
只有一边非空        → 把这一边继续往上传
左右都为空          → 返回 nullptr
```

## 4. 什么时候用值传递，什么时候共享状态

如果左右子树应该互不影响，优先考虑值传递。例如：

```cpp
dfs(root->left, state);
dfs(root->right, state);
```

两个递归分支分别拿到 `state` 的副本。

如果所有递归层必须共享同一个变化结果，可以考虑：

- 引用参数
- 成员变量
- 全局变量

例如 BST 第 K 小中的 `int& k`，所有递归层需要共享同一份访问计数。

---

## 5. 记忆句

> 向下传：当前节点先改状态，再交给左右子树。  
> 向上收：左右子树先返回结果，当前节点再做判断。
