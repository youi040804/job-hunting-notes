# 二叉树遍历（DFS 与按层 BFS）

## 1. 递归 DFS 模板

三种递归遍历的框架完全一样，差别只在“处理当前节点”这一句的位置。

```cpp
void preorder(TreeNode* root, vector<int>& res) { // 中左右
    if (root == nullptr) return;
    res.push_back(root->val);
    preorder(root->left, res);
    preorder(root->right, res);
}

void inorder(TreeNode* root, vector<int>& res) { // 左中右
    if (root == nullptr) return;
    inorder(root->left, res);
    res.push_back(root->val);
    inorder(root->right, res);
}

void postorder(TreeNode* root, vector<int>& res) { // 左右中
    if (root == nullptr) return;
    postorder(root->left, res);
    postorder(root->right, res);
    res.push_back(root->val);
}
```

`vector<int>& res` 必须是引用传递，所有递归调用才能向同一个结果数组添加元素；如果值传递，每层都在修改自己的副本。

## 2. 层序遍历：队列 BFS

适用：逐层输出、每层最大值/最右值、Z 字形遍历、最小深度等。

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> res;
    if (root == nullptr) return res;

    queue<TreeNode*> que;
    que.push(root);
    while (!que.empty()) {
        int level_size = que.size();
        vector<int> level;

        for (int i = 0; i < level_size; ++i) {
            TreeNode* node = que.front();
            que.pop();
            level.push_back(node->val);

            if (node->left != nullptr) que.push(node->left);
            if (node->right != nullptr) que.push(node->right);
        }
        res.push_back(level);
    }
    return res;
}
```

关键是**每轮先固定 `level_size = que.size()`：它代表当前层节点数**。即使本轮把下一层节点加入队列，也不会影响当前层循环次数。

## 3. 常见变形

| 题目目标 | 在层序模板上怎么改 |
| --- | --- |
| 右视图 | 记录每层最后一个出队节点的值 |
| 左视图 | 记录每层第一个出队节点的值 |
| 每层最大值 | 每层循环内维护 `max_val` |
| Z 字形遍历 | 偶数层正序加入、奇数层逆序加入 |
| 最小深度 | 第一次遇到叶子节点时返回当前层数 |

## 4. 易错点

- `queue` 用 `push()` 入队、`front()` 取队首、`pop()` 出队。
- `vector` 用 `push_back()`；不要和 `queue` 的 `push()` 混淆。
- 空树不是异常：空 `vector` 可以直接安全返回。
- 时间复杂度通常是 `O(n)`；队列空间最坏为 `O(n)`。
