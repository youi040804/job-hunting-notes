## 题1：56. 合并区间

### 类型

排序 + 区间合并。

### 为什么想到？

区间顺序混乱时，先按照左端点排序，使可能重叠的区间靠在一起。

之后只需要维护当前已经合并好的最后一个区间。

### 流程

1. 对区间按照左端点升序排序；
2. 第一个区间先加入 `res`；
3. 当前区间与 `res.back()` 比较；
4. 如果：

```cpp
res.back()[1] >= intervals[i][0]
```

说明两个区间重叠，更新右端点：

```cpp
res.back()[1] = max(res.back()[1], intervals[i][1]);
```

5. 如果不重叠，直接加入结果：

```cpp
res.push_back(intervals[i]);
```

### 易错点

- 比较的是 `res.back()`，不是固定比较原数组相邻两个区间；
- `res.back()[1]` 表示结果中最后一个区间的右端点；
- 更新右端点要使用 `max`。

### 代码

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());

        vector<vector<int>> res;
        res.push_back(intervals[0]);

        for (int i = 1; i < intervals.size(); i++) {
            if (res.back()[1] >= intervals[i][0]) {
                res.back()[1] = max(res.back()[1], intervals[i][1]);
            } else {
                res.push_back(intervals[i]);
            }
        }

        return res;
    }
};
```

### 复杂度

时间：`O(n log n)`。

空间：结果数组最坏 `O(n)`。


## 题2：739. 每日温度

### 类型

单调栈。

### 为什么想到？

题目要求寻找：

```text
右边第一个比当前元素大的位置
```

这是典型单调栈问题。

栈中保存的是还没有找到更高温度的天数下标，而不是温度本身。

### 核心思路

遍历当前温度时，如果：

```cpp
temperatures[i] > temperatures[stk.top()]
```

说明当前第 `i` 天就是栈顶那一天遇到的第一个更高温度。

因此：

```cpp
answer[k] = i - k;
```

并不断弹栈，直到当前温度不能再解决栈顶元素。

### 流程

```cpp
while (!stk.empty() &&
       temperatures[i] > temperatures[stk.top()]) {
    int k = stk.top();
    stk.pop();
    answer[k] = i - k;
}

stk.push(i);
```

### 易错点

- 栈中存的是下标；
- 要使用 `while`，因为一个较高温度可能同时解决多个旧元素；
- 先保存 `stk.top()`，再 `pop()`；
- 当前下标应该：

```cpp
stk.push(i);
```

而不是加入 `answer`；
- `answer` 已经初始化为全 0，没有找到更高温度的位置自然保持 0。

### 代码

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        vector<int> answer(temperatures.size(), 0);
        stack<int> stk;

        for (int i = 0; i < temperatures.size(); i++) {
            while (!stk.empty() &&
                   temperatures[i] > temperatures[stk.top()]) {

                int k = stk.top();
                stk.pop();

                answer[k] = i - k;
            }

            stk.push(i);
        }

        return answer;
    }
};
```

### 复杂度

时间：`O(n)`。

每个元素最多入栈一次、出栈一次。

空间：`O(n)`。

## 今日复盘结论

- 合并区间：排序后维护 `res.back()`，重叠就扩展右边界。
- 每日温度：看到“右边第一个更大元素”，优先想到单调栈。
- 单调栈中存下标，可以方便计算距离。
