# 8月13日旧题复盘

## 题1：160. 相交链表

### 类型

链表 + 双指针。

### 为什么想到？

两条链表前缀长度可能不同，但相交后的尾部完全相同。让两个指针分别走完“自己的链表 + 对方的链表”，就能抵消长度差。

### 流程

- p 从 headA 出发，走到末尾后切到 headB；
- q 从 headB 出发，走到末尾后切到 headA；
- 两指针相等时返回该节点；不相交时会同时为 `nullptr`。

### 复杂度

时间：O(m+n)

空间：O(1)

代码：
```
ListNode*p=headA; 
ListNode*q=headB; 
while(p!=q){ 
	p=p?p->next:headB; 
	q=q?q->next:headA; 
} 
return p
```

## 题2：206. 反转链表

### 类型

链表指针操作。

### 为什么想到？

修改 `cur->next` 前，必须先保存原本的下一个节点，否则后半段链表会丢失。

### 流程

- `pre` 初始化为 `nullptr`，`cur` 初始化为 `head`；
- 保存 `cur->next`；
- 让 `cur->next` 指向 `pre`；
- `pre`、`cur` 同步后移；
- 循环结束后返回 `pre`。

### 复杂度

时间：O(n)

空间：O(1)

代码：
```
ListNode*cur=head,*pre=nullptr; 
while(cur!=nullptr){ 
	ListNode*temp=cur->next; 
	cur->next=pre; 
	pre=cur; 
	cur=temp; 
}
return pre;
```
