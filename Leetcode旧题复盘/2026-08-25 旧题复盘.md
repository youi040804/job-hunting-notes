## 1. 11. 盛最多水的容器

### 类型

对撞双指针。

### 思路

左右指针分别从数组两端开始。

当前容量：

```cpp
min(height[left], height[right]) * (right - left)
```

每次移动高度较小的一侧。

因为指针向内移动后宽度一定减小，如果移动较高的一侧，短板高度没有改变，不可能通过高度弥补宽度损失；移动较矮的一侧才有机会找到更高的边界。

### 核心

> 短板高度 × 宽度 → 更新最大值 → 移动短板。

### 我的漏洞

算法模型记得比较清楚，但第一次写代码时把面积公式写成了：

```cpp
(height[right] - height[left]) * (right - left)
```

正确公式不是“高度差 × 宽度”，而是：

```cpp
min(height[left], height[right]) * (right - left)
```

另外，每轮只需要：

1. 计算当前面积；
2. 更新最大值；
3. 移动较矮的一侧。

不需要移动指针前后重复计算面积。

### 复杂度

时间：O(n)

空间：O(1)

## 2. 146. LRU Cache

### 类型

哈希表 + 双向链表。

### 思路

哈希表：

```cpp
unordered_map<int, Node*> mp;
```

负责通过 key 在 O(1) 时间找到节点。

双向链表负责维护使用顺序：

- 靠近 `head`：最近使用；
- 靠近 `tail`：最久未使用。

访问或更新节点后，将节点移动到头部。

容量超过限制时，删除：

```cpp
tail->prev
```

也就是最近最少使用的节点。

### 两个核心辅助函数

#### removeNode

只负责把节点从链表当前位置摘下来：

```cpp
node->prev->next = node->next;
node->next->prev = node->prev;
```

注意：

> `removeNode()` ≠ 删除整个缓存。

节点被访问后也需要先 `removeNode` 再 `addToHead`，所以这里不能直接 `mp.erase()`。

#### addToHead

把节点插入 `head` 后面，需要维护四条指针关系：

```cpp
node->next = head->next;
node->prev = head;
head->next->prev = node;
head->next = node;
```

### get

- 哈希表找不到：返回 `-1`；
- 找到：取出节点；
- 从原位置摘下；
- 移到链表头部；
- 返回 `value`。

### put

key 已存在：

- 更新 `value`；
- 移到链表头部。

key 不存在：

- 创建新节点；
- 加入哈希表；
- 插入链表头部；
- 如果容量超限，删除 `tail->prev`；
- 同时从哈希表删除并释放节点。

### 我的漏洞

整体模型记得比较牢，但双向链表代码细节还不够稳：

1. `prev`、`next` 应该是 `Node*`；
2. `head`、`tail` 应该作为成员保存，连接关系放在构造函数中初始化；
3. `removeNode()` 只负责链表摘除，不能顺手 `mp.erase()`；
4. `addToHead()` 的四条指针关系容易写错；
```
先让 node 连接两边：
node->prev = head;
node->next = head->next;

再让两边反过来指向 node：
head->next->prev = node;
head->next = node;
```

1. 长代码题不需要每次完整默写，但这些核心链表操作需要再熟练。

### 核心

> 哈希表负责 O(1) 找节点，双向链表负责 O(1) 调整使用顺序；访问后移头，超容量删尾。

## 3. 155. 最小栈

### 类型

栈 + 辅助栈。

### 思路

使用两个栈：

- `stk`：正常保存所有元素；
- `minStk`：保存当前仍然有效的最小值。

入栈时：

```cpp
if (minStk.empty() || value <= minStk.top()) {
    minStk.push(value);
}
```

必须使用 `<=`，而不是 `<`。

例如连续压入两个 `3`，辅助栈也必须记录两个 `3`，否则弹掉一个 `3` 后会丢失正确的最小值。

出栈时：

```cpp
if (stk.top() == minStk.top()) {
    minStk.pop();
}

stk.pop();
```

### 核心

> 普通栈存数据，辅助栈保存当前有效的最小值历史。

### 我的漏洞

本题整体已经比较熟练。

需要继续注意两个细节：

1. 重复最小值必须使用 `<=`；
2. LeetCode 已经保证 `pop`、`top`、`getMin` 在栈非空时调用，因此不需要习惯性重复判断 `empty()`。

算法题中应先查看题目给出的前置条件：

> 题目已经保证合法，就不用重复做防御性判断。

### 复杂度

`push`、`pop`、`top`、`getMin` 均为 O(1)。
