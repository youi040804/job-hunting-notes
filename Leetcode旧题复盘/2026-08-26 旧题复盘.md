## 题1：15. 三数之和

### 类型

排序 + 固定一个数 + 对撞双指针。

### 为什么想到？

三数之和可以转化成"固定一个数，再在剩余有序区间中寻找两数之和"。排序以后，左右指针的移动具有单调性：当前和偏小就右移`left`，当前和偏大就左移 `right`。

### 流程

1.  先对数组升序排序；
2.  枚举 `k`，固定 `nums[k]`；
3.  `left = k + 1`，`right = n - 1`；
4.  当 `left < right` 时计算三数之和；
5.  `sum < 0`：`left++`；
6.  `sum > 0`：`right--`；
7.  `sum == 0`：记录三个数，对 `left/right` 去重后继续移动。

### 去重

这题的去重不是"看到重复数字就全部跳过"，而是为了防止同一个三元组被重复加入答案。

固定值 `k` 去重：

``` cpp
if (k > 0 && nums[k] == nums[k - 1]) {
    continue;
}
```

因为前一个相同的固定值已经搜索过全部组合，再搜索一次只会产生重复答案。

找到答案以后，对 `left/right` 去重：

``` cpp
while (left < right && nums[left] == nums[left + 1]) {
    left++;
}

while (left < right && nums[right] == nums[right - 1]) {
    right--;
}
//先去重，再移动 
left++;
right--;
```

`sum < 0` 或 `sum > 0` 时不进行去重也不会影响正确性，因为此时还没有向结果集中加入答案；最多只是重复做几次相同判断。

### 易错点

-   `sum` 必须放在 `while` 内每轮重新计算，因为 `left/right` 会移动；
-   结果中保存的是 `{nums[k], nums[left], nums[right]}`，不是三个下标；
-   循环条件是 `left < right`，三个数必须来自三个不同位置；
-   本次复盘主体双指针思路已掌握，但去重逻辑需要再次复盘。

### 代码

``` cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());

        vector<vector<int>> res;
        int n = nums.size();

        for (int k = 0; k < n - 2; k++) {
            if (k > 0 && nums[k] == nums[k - 1]) {
                continue;
            }

            int left = k + 1;
            int right = n - 1;

            while (left < right) {
                int sum = nums[k] + nums[left] + nums[right];

                if (sum == 0) {
                    res.push_back({nums[k], nums[left], nums[right]});
                     
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;
					
					//先去重，再移动 
		            left++;
		            right--;
                } else if (sum < 0) {
                    left++;
                } else {
                    right--;
                }
            }
        }

        return res;
    }
};
```

### 复杂度

时间：`O(n^2)`。

空间：若不计排序内部空间和返回结果，可视为 `O(1)`。


## 题2：98. 验证二叉搜索树

### 类型

BST + 中序遍历 + 递归返回值。

### 为什么想到？

二叉搜索树的中序遍历结果必须严格递增。因此不需要只比较当前节点和左右孩子，而是在中序遍历过程中记录"上一个访问到的节点值"，检查整个中序序列是否始终递增。

只比较父子节点是不够的，因为 BST
要求整个左子树都小于当前节点、整个右子树都大于当前节点。

### 流程

-   空节点返回 `true`；
-   先递归判断左子树；
-   左子树返回 `false` 时必须立即向上传递；
-   访问当前节点，如果`root->val <= pre`，说明中序序列不再严格递增，返回 `false`；
-   更新 `pre`；
-   最后递归判断右子树，并直接返回结果。

### 易错点

本次代码中的主要问题是：

``` cpp
isValidBST(root->left);
```

这里只调用了递归，却没有处理它的返回值。如果左子树已经返回
`false`，当前层仍然会继续执行。应该写成：

``` cpp
if (!isValidBST(root->left)) {
    return false;
}
```

右子树位于当前函数最后，因此可以直接：

``` cpp
return isValidBST(root->right);
```

核心提醒：

> 调用递归函数，不等于处理了递归函数的返回值。

### 代码

``` cpp
class Solution {
    long long pre = LLONG_MIN;

public:
    bool isValidBST(TreeNode* root) {
        if (root == nullptr) {
            return true;
        }

        if (!isValidBST(root->left)) {
            return false;
        }

        if (root->val <= pre) {
            return false;
        }

        pre = root->val;

        return isValidBST(root->right);
    }
};
```

### 复杂度

时间：`O(n)`，每个节点最多访问一次。

空间：`O(h)`，主要来自递归调用栈；平衡树约为`O(log n)`，退化成链表时最坏为 `O(n)`。
