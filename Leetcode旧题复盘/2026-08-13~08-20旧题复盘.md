# 8月13日旧题复盘

## 题1：160. 相交链表

### 类型

链表 + 双指针。

### 为什么想到？

两条链表前缀长度可能不同，但相交后的尾部完全相同。让两个指针分别走完“自己的链表 + 对方的链表”，就能抵消长度差。

### 流程

- p 从 headA 出发，走到末尾后切到 headB；
- q 从 headB 出发，走到末尾后切到 headA；
- 两指针相等时返回该节点；不相交时会同时为 `nullptr`。

### 复杂度

时间：O(m+n)

空间：O(1)

代码：
```
ListNode*p=headA; 
ListNode*q=headB; 
while(p!=q){ 
	p=p?p->next:headB; 
	q=q?q->next:headA; 
} 
return p
```

## 题2：206. 反转链表

### 类型

链表指针操作。

### 为什么想到？

修改 `cur->next` 前，必须先保存原本的下一个节点，否则后半段链表会丢失。

### 流程

- `pre` 初始化为 `nullptr`，`cur` 初始化为 `head`；
- 保存 `cur->next`；
- 让 `cur->next` 指向 `pre`；
- `pre`、`cur` 同步后移；
- 循环结束后返回 `pre`。

### 复杂度

时间：O(n)

空间：O(1)

代码：
```
ListNode*cur=head,*pre=nullptr; 
while(cur!=nullptr){ 
	ListNode*temp=cur->next; 
	cur->next=pre; 
	pre=cur; 
	cur=temp; 
}
return pre;
```

## 8月18日旧题复盘

### 1. 234. 回文链表

### 思路

以：

1 -> 2 -> 3 -> 2 -> 1

为例。

这题核心是：

> 判断链表前半部分和后半部分是否完全相同。

由于链表无法直接通过下标访问，所以不能像数组一样左右比较。

整体思路：

1. 使用快慢指针找到链表中点；
2. 从中点开始反转后半部分链表；
3. 分别从原链表头节点和反转后的后半部分头节点开始遍历；
4. 比较两个链表节点值是否一致。

如果所有节点都相同，则说明是回文链表。

核心：

回文链表=找中点+反转后半部分+双指针比较

复杂度：

时间：O(n)

空间：O(1)

### 2. 141. 环形链表

### 思路

这题最经典的解法：

**快慢指针（龟兔赛跑）。**

设置：

- slow：每次移动一步；
- fast：每次移动两步。

如果链表没有环：

- fast 最终会走到 nullptr；
- 返回 false。

如果链表存在环：

- fast 会不断在环中追赶 slow；
- 两者一定会相遇。

因此判断条件：

if(slow == fast)

    return true;

核心：

> 快慢指针速度不同，在有限环中一定会产生相遇。

复杂度：

时间：O(n)

空间：O(1)

### 3. 21. 合并两个有序链表

### 思路

这题主要是双指针模板。

两个链表：

1 -> 3 -> 5

2 -> 4 -> 6

每次比较两个链表当前节点：

- 较小节点加入结果链表；
- 对应指针后移。

为了避免处理头节点特殊情况，使用 dummy 哨兵节点：

ListNode dummy;

ListNode* cur=&dummy;

然后：

cur->next = 较小节点;

cur = cur->next;

最后将剩余链表直接连接：

cur->next = list1 ? list1 : list2;

核心：

> dummy 节点简化链表头节点处理，cur 始终维护当前结果链表尾部。

复杂度：

时间：O(n+m)

空间：O(1)
